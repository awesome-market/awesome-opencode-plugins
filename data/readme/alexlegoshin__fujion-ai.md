# FUJION-AI

**Локальная ИИ-станция на старом железе.** Пять кодинг-агентов, свой маршрутизатор запросов к моделям, пульт управления, мост в Windows с подтверждением человеком, песочница, аварийный сторож железа и генерация медиа — всё на одном домашнем ПК, без облака.

> Self-hosted AI workstation: five coding agents (opencode, hermes, kimi-code, prime, claude-code) behind a local model router (llama.cpp / llama-swap), a web control panel, a human-approved bridge to Windows, a bwrap sandbox and a hardware watchdog — on a 2012-era FX-8320 with a TITAN X Pascal.

---

## Железо и идея

| | |
|---|---|
| CPU | AMD FX-8320, 8 ядер, 4.3 ГГц, **без AVX2** |
| RAM | 32 ГБ DDR3 (WSL получает 23.5 ГБ, Windows — всегда главнее) |
| GPU | NVIDIA TITAN X Pascal 12 ГБ (sm_61) — модели; GTX 960 — браузеры, распознавание речи |
| ОС | Windows 10 + WSL2 (Ubuntu 24.04) |

Задача станции — чтобы старая машина работала как полноценный «ИИ-офис»: агенты пишут код в своих проектах, модели меняются под задачу, человек видит и подтверждает всё, что выходит за песочницу, а Windows никогда не остаётся без памяти.

## Из чего состоит

```
                 человек
                    │
        ┌───────────┴───────────┐
        │   ЦУП (cup/) :7000    │  пульт: чат, агенты, медиа, управление, подтверждения
        └───────────┬───────────┘
                    │
   агенты в песочнице (sandbox/, bwrap) ── мост в Windows (bridge/) :7010 ── cmd/PowerShell с подтверждением
                    │
        ┌───────────┴───────────┐
        │ Диспетчер (dispatcher/) :8090 │  сессии, ходы, шаги, оценки, выбор модели, страж памяти, очередь
        └───────────┬───────────┘
                    │
        llama-swap :8080 (models/llama-swap.yaml) ── llama.cpp (sm_61) ── модели на D: и C:
```

## Ключевые механики

- **Шаги и оценки.** Шаг = новое сообщение человека агенту. Диспетчер сам находит границы ходов в потоке запросов агента (служебные вставки агентов — сжатие, уведомления, «продолжай» — не считаются), считает время, токены, ошибки инструментов; человек ставит оценку 1–7 и сложность. Всё пишется для статистики.
- **Память Windows — главнее.** Если Windows не хватает RAM/VRAM, Диспетчер выгружает модель (даже посреди ответа при удушье), сбрасывает кэш WSL и честно отвечает агенту «уступил Windows».
- **Мост с подтверждением.** Агент в WSL просит выполнить команду в Windows — человек в ЦУП разрешает или запрещает; в лайт-контроле решает политика (`bridge/policy.py`), опасное (реестр, соглашения, установки в общее окружение) всё равно спрашивает.
- **Песочница и корзина.** Агенты не видят папку с админ-скриптами, удаление файлов уходит в `.fujion-trash` проекта.
- **Аварийный сторож.** Windows-задача читает датчики (LibreHardwareMonitor): перегрев сокета/GPU и провал +12V → сначала гасит стресс-тесты и модели, при критике — выключение ПК; каждый сбой — архив с журналом и снимком датчиков.
- **Видеокарты.** TITAN X целиком под модели: браузеры и Electron-программы уходят на GTX 960 (`windows/tools/gpu960.ps1`), распознавание речи — тоже на 960.

## Установка (кратко)

Подробно — по шагам в [`wsl/install/README.md`](wsl/install/README.md) и в `windows/steps/`. Коротко:

1. Windows: WSL2 + Ubuntu 24.04, драйвер NVIDIA, LibreHardwareMonitor, сторож (`windows/cmd/FUJION_guard_v21.cmd`).
2. WSL: CUDA 12.9, сборка llama.cpp под sm_61 (`wsl/install/`), llama-swap, диск моделей.
3. Агенты: `wsl/install/` (сборка opencode, uv-окружение hermes, официальные установщики kimi/prime/claude-code).
4. Диспетчер, мост, ЦУП: `cup/start.sh`; на Windows — ярлык ЦУП (`windows/tools/FUJION_CUP.vbs`).

Вне репозитория (на машине): `~/engines/{llama.cpp,ComfyUI,whisper.cpp,piper}` — движки, `/mnt/models` — модели на D:,
`~/models-nvme` — «монстр» на C:, `~/workspaces` — рабочие папки и прогоны стенда, `~/archive` — отжившее.

Пути и имена в скриптах — с конкретной машины (`/home/phoenix`, диски C:/D:/E:/F:/G:); под другую машину их нужно поправить.
