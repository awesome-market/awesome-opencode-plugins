# Agent Skills — мероприятия, афиши, сайты, печать

22 навыка для агентных ассистентов (OpenCode, Claude Code, Codex — формат `SKILL.md` с YAML-frontmatter). Написаны под реальную работу: организация форумов, афиши и брендинг, статические сайты, документы к печати, креативы для соцсетей, настройка рабочей машины.

Общий принцип: не «вдохновляющие советы», а проверяемые шаги, жёсткие правила и чек-лист перед «готово».

## Установка

```bash
git clone https://github.com/askuyr/agent-skills.git
```

Скопировать нужные папки в каталог навыков агента:

| Агент | Каталог |
|---|---|
| OpenCode (глобально) | `~/.config/opencode/skills/` |
| OpenCode / общий для агентов | `~/.agents/skills/` |
| Claude Code | `~/.claude/skills/` |

Перезапустить агент. Каждый навык — папка с `SKILL.md`, внешних зависимостей нет (у `opencode-go-limits` — один Python-скрипт, у `site-ship` — справочник по деплою).

```bash
cp -r agent-skills/skills/* ~/.agents/skills/
```

## Как устроен навык

```markdown
---
name: event-program
description: Программа и тайминг мероприятия. Использовать на «собери программу форума», ...
---

# Программа мероприятия

## 0. Источник правды
...
```

- `description` содержит формулировки, на которых навык должен срабатывать, — это единственное, что агент видит до загрузки;
- тело — процедура с проверками и разделом «Ограничения»;
- личные пути не зашиты: `$env:USERPROFILE`, `~/Desktop/<project>`, `<user>/<repo>` вместо конкретных.

## Совместимость

- Формат `SKILL.md` (YAML frontmatter + markdown) — стандарт Agent Skills.
- `smm-design-check` и `svg-assets` используют встроенный браузер агента (`browser.*`) для проверки результата; без него дают ручной чек-лист.
- Windows-специфика: `desktop-cleanup`, `opencode-go-limits`, `windows-soft-setup` (PowerShell), остальные кроссплатформенные.
