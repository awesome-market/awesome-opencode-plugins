# Manage Agents

## Install

```sh
opencode plugin add 'github:abran-labs/opencode-manage-agents#v0.1.0'
```

## Desktop

Open **Manage agents** from the agent menu or command palette.

![Open Manage agents from the Build dropdown beside the model selector in the chat composer](.github/assets/manage-agents-menu.svg)

View all your agents, including subagents.

![Agent picker showing Build and Plan under Primary agents, and General and Explore under Subagents](.github/assets/agent-picker.svg)

Configure the default models they should use and fallbacks for when you run out of usage.

![Fallback 1 selected with a checkmark beside Claude Fable 5.2](.github/assets/fallback-picker.svg)

## Uninstall

```sh
opencode plugin remove 'github:abran-labs/opencode-manage-agents#v0.1.0'
```
