# opencode-session-tokens

Плагин для OpenCode, который показывает расход токенов и стоимость текущей сессии: панель с детализацией (входящие, исходящие, рассуждения, кэш, ходы, субагенты, стоимость), строку статуса внизу окна и пилюлю `Σ <сумма>` рядом с индикатором контекста в композере.

## Возможности

- **Боковая панель «Токены сессии»** — суммарные токены сессии по категориям: входящие, исходящие, рассуждения (reasoning), кэш (чтение/запись), количество ходов и стоимость в `$`; плюс суммарные токены и кэш всех субагентов сессии (строки «Субагенты» и «Кэш субагентов» появляются, когда в сессии есть субагенты).
- **Пилюля в композере** — компактный индикатор `Σ 12.3k ⟳ 85.4k/2.1k` рядом с «NN% ctx»: `Σ` — входящие+исходящие+рассуждения, `⟳` — кэш чтение/запись; обновляется автоматически (~каждые 5 секунд), клик открывает панель. Показывает подробности в подсказке при наведении.
- **Строка статуса внизу окна** — краткая сводка `Σ in … · out … · $…` для текущей сессии.
- **Слэш-команда `/tokens`** («Показать токены сессии») — открывает/закрывает панель.
- **Локализация** — встроенные переводы на английский и русский языки.
- **Устойчивое чтение данных** — получение сообщений сессии через SDK OpenCode с перебором нескольких методов API (`session.messages`, `session.message.list`, `session.context`); при отсутствии токенов в ответе показывает ключи сообщений для отладки. Токены субагентов берутся из готовых агрегатов хоста через `session.list` с фильтром `parentID`, включая вложенных субагентов.

## Технологический стек

- **TypeScript** (strict, ES2022) — язык плагина.
- **[SolidJS](https://www.solidjs.com/) ≥ 1.9** — реактивный UI GUI-части.
- **[@opencode/plugin](https://opencode.ai/docs/build/plugins) ≥ 2.2.0** — SDK плагинов OpenCode (серверная и GUI-части).
- **[Vite](https://vite.dev/) 7 + vite-plugin-solid** — сборка GUI-бандла через пресет `@opencode/plugin/gui/vite`.

Пакеты `@opencode/plugin` и `solid-js` объявлены как опциональные peer-зависимости: в рантайме их предоставляет само приложение OpenCode.

## Установка и настройка

### Требования

- OpenCode Desktop (GUI-часть плагина работает в десктоп-приложении).

### Установка

Плагин устанавливается одной командой из CLI OpenCode:

```bash
opencode plugin add github:alexandr777git/opencode-session-tokens
```

Если бинарник называется иначе, работает эквивалентный вариант:

```bash
opencode-cli plugin add github:alexandr777git/opencode-session-tokens
```

## Использование

1. Установите плагин командой `opencode plugin add github:alexandr777git/opencode-session-tokens` (см. [Установка и настройка](#установка-и-настройка)).
2. Откройте OpenCode Desktop и начните сессию.

Примеры работы с плагином:

- Слэш-команда в композере:

  ```text
  /tokens
  ```

  Открывает боковую панель с детализацией токенов текущей сессии.

- Пилюля в композере рядом с индикатором контекста показывает суммарные токены сессии и кэш:

  ```text
  Σ 12.3k ⟳ 85.4k/2.1k
  ```

  `Σ` — входящие+исходящие+рассуждения; `⟳` — кэш чтение/запись. Наведение — подробности по категориям; клик — открыть/закрыть панель.

  Панель дополнительно показывает расход субагентов — строки появляются, когда в сессии есть субагенты (сумма по всем вложенным дочерним сессиям):

  ```text
  Ходов              42
  Субагенты       74 851
  Кэш субагентов  2 100 224 / 0
  ```

Внизу окна постоянно отображается сводка вида `Σ in 4 512 · out 1 203 · $0.0310`.

## Структура проекта

```text
├── src/
│   ├── index.ts                # серверная часть: регистрация плагина (id: session-tokens)
│   └── gui.tsx                 # GUI-часть: панель, статус-строка, /tokens, пилюля композера
├── dist/
│   └── gui-experimental.cjs    # собранный GUI-бандл (экспорт ./gui-experimental)
├── vite.config.ts              # конфигурация Vite с пресетом gui() из @opencode/plugin/gui/vite
├── tsconfig.json               # настройки TypeScript (strict, JSX: solid-js)
└── package.json                # манифест пакета, exports и peer-зависимости
```

Счётчик токенов целиком живёт в GUI-части (`src/gui.tsx`); серверная часть (`src/index.ts`) нужна только для регистрации плагина с явным `id`.

## Конфигурация

- Переменные окружения и опции плагина не используются.
- Единственная точка настройки — установка плагина через `opencode plugin add` (см. [Установка и настройка](#установка-и-настройка)).
- Язык интерфейса (en/ru) подставляется автоматически из встроенных переводов `i18n` в `src/gui.tsx`.
