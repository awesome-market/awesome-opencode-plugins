# Octopus Plugins

Octopus 插件集合。

## WorkBuddy

- 目录：`plugins/octopus-plugin-workbuddy-auth`
- 插件 ID：`@cend/octopus-plugin-workbuddy-auth`
- 显示名：WorkBuddy
- 版本：1.0.0
- 支持：WorkBuddy（国内版）、WorkBuddy AI（国际版）

基于上游 `@magpie-community/opencode-workbuddy-auth@0.2.20` 适配，保留原项目的 MIT 许可证和署名信息。

### 安装

在 Octopus 的「插件」页直接填写 npm 包名：

```text
@cend/octopus-plugin-workbuddy-auth@1.0.0
```

也可以克隆本仓库后填写本地目录：

```text
<仓库路径>/plugins/octopus-plugin-workbuddy-auth
```

或在打包后填写生成的 `.tgz` 文件路径。
