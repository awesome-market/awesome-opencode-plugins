# agent-kit

Переносимый набор для других проектов: пайплайн и четыре пакета. Скиллы конкретного продукта сюда не входят.

| Каталог | Когда пайплайн его читает |
|---|---|
| `implementation-pipeline/` | Скилл прикреплён к запросу |
| `front/` | В `.cursor/project.md` есть вид «веб» |
| `des/` | Вид «десктоп» |
| `back/` | Вид «бэкенд» |
| `mob/` | Вид «мобилка» |

Порядок внутри пакета задаёт его `rules/*.mdc`. Тексты правил уже заполнены.

## Как подключить в другом проекте

1. Скопировать каталог `agent-kit` в корень того проекта.
2. Скопировать `agent-kit/implementation-pipeline` в `~/.cursor/skills/implementation-pipeline`, чтобы скилл можно было прикрепить к запросу.
3. Первый ход пайплайна: если в проекте нет `.cursor/project.md`, агент записывает виды и стек по манифестам. Вопрос задаёт только если вид не разобрать. Папку `agent-kit` признаком вида не считает.

Проверка состава: `bash agent-kit/scripts/check-kit.sh`.
