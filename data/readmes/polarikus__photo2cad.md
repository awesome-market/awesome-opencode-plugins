# photo2cad

Фреймворк для OpenCode: реверс-инжиниринг деталей по фотографиям и эскизам
с параметрическим 3D-моделированием под FDM-печать.

Не «ИИ рисует модель», а дисциплинированный конвейер:

```text
фото/эскиз → масштабный якорь → таблица размеров → параметрическая модель
          → ортогональные виды → наложение на фото → печать → правки
```

## Почему так

На фотографии нет миллиметров. Любая модель, построенная «на глаз», — это
скульптура, а не деталь. Поэтому фреймворк требует:

- **масштабный якорь** (линейка, монета, A4, штангенциркуль или 2–3 размера);
- **источник у каждого размера** (`measured` / `estimated` / `assumed`);
- **закрытую проверку**: рендер ортогональных видов и наложение на фото.

## Быстрый старт

```sh
# 1. окружение
./scripts/setup.sh

# 2. проверка
./scripts/doctor.sh

# 3. новая деталь
/spec parts/my-part/photos/front.jpg parts/my-part/photos/side.jpg
```

Дальше по циклу: `/clarify` → `/plan` → `/tasks` → `/implement` → `/verify` → `/export`.

## Требования

- macOS или Linux, Python 3.12;
- [uv](https://docs.astral.sh/uv/) для виртуального окружения;
- FreeCAD 1.x с аддоном `FreeCADMCP` — для видов, FEM и чертежей;
- OpenCode с поддержкой MCP и скилов.

`build123d` ставится в `.venv` скриптом `setup.sh`. FreeCAD MCP подключается
через `opencode.json` и работает, только когда FreeCAD запущен.

## Опционально: text-to-cad

[text-to-cad](https://github.com/earthtojake/text-to-cad) — MIT-проект на том же
`build123d`: viewer, DFM, чертежи, 3MF, G-code. Он не заменяет `photo2cad`, а
даёт более сильный движок вывода файлов.

```sh
./scripts/setup-text-to-cad.sh
```

Скрипт ставит text-to-cad и включает MCP-сервер `cad` в `opencode.json`
(по умолчанию он выключен). Требуется `uv` и ~220 МБ на ядро OCP.

Правило остаётся: внешний инструмент даёт **черновик**, а не истину. Черновик
проходит тот же аудит размеров, что и ручная модель. Подробнее —
`docs/ecosystem.md`.

## Ограничения

Честно: точность по фото без якоря — ±10–20 %, с якорем — ±1–3 мм на габаритах
и хуже на мелких фичах. Сложные поверхности (лопатки, органика) этим путём не
делаются. Подробнее — `docs/limitations.md`.
