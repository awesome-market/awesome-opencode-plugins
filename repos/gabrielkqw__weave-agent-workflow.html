 ⚡ Stop Claude Code, Codex & Antigravity from burning your context window

Every time your AI coding agent runs a terminal command, verbose logs flood its context window. Within 5–10 steps, the agent slows down, loses focus, forgets earlier instructions, and hits context limits:

| ❌ Raw Shell (Without Weave) | ✅ With Weave (Intelligent Compression) |
| :--- | :--- |
| git status → 84 lines of unchanged filesnpm test → 340 lines of passing test dotsnpm run build → 120 lines progress bars💥 ~15,000 to 50,000 wasted context tokens per run⚠️ Agent loses previous code context and hallucinates💸 Multiplies API token costs unnecessarily | git status → 4 lines (condensed summary + SHA recall)npm test → 2 lines (pass summary; failures kept 100%)npm run build → 1 line (clean outcome confirmation)⚡ Cuts terminal token usage by up to 96.4%🎯 Keeps agent context clean, sharp, and focused🔒 Zero loss: full raw output recoverable via weave recall |

 Why Weave?

Long agent sessions rot the same way every time: terminal output balloons, the same file gets re-read, an unrequested abstraction creeps in, and "done" gets claimed without proof. Weave is the layer that stops that pattern — one dependency-free plugin that cuts eligible successful output by up to 96.4% (see Benchmarks), keeps a compact .weave/state.md handoff between Claude Code, Codex CLI, and Antigravity CLI, and enforces reuse-first, evidence-before-claims engineering discipline.

Weave combines the useful ideas behind minimal coding discipline and reduced terminal noise without copying Ponytail or RTK code and without depending on either runtime. The core uses Node.js standard-library modules only: no daemon, database, or third-party package. An optional dependency-free MCP server ships in mcp/server.js for MCP-capable clients that have no native Weave plugin (see MCP server).

 See Weave in Action

console
$ node cli/weave.js exec -- "git status"
Command: git status
Exit: 0
Summary: git status (long file lists condensed)
Failures: none
Omitted: 4 line(s)
Recovery: weave recall 4f12ab90cd34


The original command runs unchanged. Weave preserves its exit code, reduces only eligible successful output, and stores a redacted recovery capture when content is omitted.
