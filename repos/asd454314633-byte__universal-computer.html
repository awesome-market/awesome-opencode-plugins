README

UniversalComputer｜Windows 电脑自动化与 AI Agent Computer Use

跨宿主的电脑操作工具：Python + CLI + JSON，让 AI Agent 在 Windows 上操作浏览器、桌面控件和命令行。
支持 WorkBuddy、Codex、Qoder CN 等能够启动进程并读取 JSON 的调用方；不需要安装专属 Agent 服务。

English README · 快速安装 · 功能范围 · CLI 调用示例 · Agent Skill · 12 项验收记录 · 安全模型

与任何 Agent 宿主解耦的通用电脑操作核心：把「操作浏览器、Windows 桌面软件、
窗口控件、命令行」的能力收敛为一套宿主中立的 CLI + JSON 协议。
任何能「启动进程 + 解析 JSON」的 Agent（WorkBuddy / Codex / 自研脚本均可）
都可以调用它，无需绑定特定宿主。

- 许可证：MIT（自研代码，见 LICENSE）；第三方依赖出处见 THIRD_PARTY_NOTICES.md
- 平台：Windows 10/11，Python 3.11+（3.13 验证）
- 形态：纯 Python 代码库 + 可选的 Agent Skill 包（skill/），无服务、无后台驻留

自主开发声明： Universal Computer 的公开核心程序、统一任务路由、执行适配层、CLI、Skill 和相关项目文档由本项目开发者自主编写、整合并维护。系统使用公开的第三方软件 API 与开源依赖，不宣称对 Playwright、Windows UIA、Win32、COM 等基础技术及其上游项目拥有原创权。详见 《自主开发与第三方依赖声明》及 第三方项目出处。

 能力范围

| 域 | 主路径 | 覆盖能力 |
|---|---|---|
| 浏览器 | Playwright（结构化 DOM） | 打开/读文本/填表/点击/截图/无障碍快照/多标签页/上传下载/iframe/dialog；支持 attach 已运行浏览器（CDP）、持久登录 Profile |
| Windows 桌面 | UIA（控件树/Pattern） | 列窗口、读控件树、按 AutomationId/Name/ControlType/ClassName 定位、invoke、set_text、get_value、focus；动作链 Pattern → WM 消息 → 键盘 |
| Windows 窗口层 | Win32（hwnd/消息） | 枚举窗口、聚焦激活、前台窗口查询 |
| Office / 原生接口 | COM（注册表探测 + 晚绑定调用） | ProgID 探测、dispatch_com 晚绑定分发 |
| 视觉兜底 | 可插拔 VisualProvider 接口 | observe/locate/click/type/drag/scroll/verify 契约 + Mock 实现（不绑定具体模型，默认关闭） |
| MCP | 接口预留 | 宿主注册 MCP server 的探测槽位（Phase 1 不含传输实现） |

工程能力：能力探测（detect）、Domain-aware 路由、声明式多步任务（uc.py run）、
失败恢复（重获取→重定位，硬上限 2 次）、任务状态机与断点续跑判定、逐动作 JSONL
审计、三级风险声明（READ / WRITE / DESTRUCTIVE）。

 三分钟上手：先在隔离环境验证

以下命令适用于 Windows PowerShell，需要 Git、Python 3.11+ 和本机 Chrome；不需要接入任何私人网站或 Agent 账号。请勿在现有生产 Python 环境内直接安装依赖。

powershell
git clone https://github.com/asd454314633-byte/universal-computer.git
cd universal-computer
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe uc.py doctor
.\.venv\Scripts\python.exe uc.py capabilities


- 看能力： doctor 和 capabilities 会报告可用的浏览器、Windows UIA/Win32 等 Provider；可选 Visual、MCP 等占位模块返回不可用是正常的。
- 试真实动作： 先阅读 安装/卸载说明 和 CLI 示例，再对你自行控制的浏览器页面或测试窗口操作。
- 看验证证据： 12/12 Phase 1 验收报告 使用了自有浏览器页面和 Windows 测试窗口；它不代表任意真实网站或软件都能无障碍自动化。
- 安全边界： 本项目仅报告 READ / WRITE / DESTRUCTIVE 风险等级；操作授权由调用方处理。参阅 风险模型 和 当前限制。

 安装

完整环境要求、隔离安装、健康检查与卸载方式见 INSTALL.md。上方命令可直接复制，无需手动替换  占位符。

doctor 为环境探测：浏览器可用时应有 capabilities.playwright: true 和
browser_live_launch: true；Windows 控件操作检查 capabilities.uia: true。
部分可选/占位 Provider 默认不可用是正常情况，不要求全部 available: true。
详见 INSTALL.md。

 调用

统一入口 uc.py，stdout 恒为单个 JSON 文档：

bash
python uc.py doctor                           健康检查
python uc.py capabilities                     各 Provider 可用性
python uc.py run task.json                    声明式多步任务
python uc.py browser open --url https://example.com
