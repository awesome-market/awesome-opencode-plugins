OpenMatthew

 Unofficial, community project. Not affiliated with Chiang Mai University or the Matthew AI team. Use your own CMU account at your own risk.

Use your CMU Matthew AI account from any app that speaks the OpenAI API. OpenMatthew runs on your computer and translates between the two.

 Quick start

You need Node.js 20 or newer, and git.

1. Get the code and install it:

   bash
   git clone https://github.com/ChindanaiNaKub/OpenMatthew
   cd OpenMatthew
   npm install
   

2. Start the server. Leave this terminal open:

   bash
   npm run serve
   

3. In a second terminal, get your token:

   bash
   npm run creds
   

   Log in at matthew.cmu.ac.th. Press F12, open the Console tab, and run copy(localStorage.user). Paste the result into the terminal and press Enter. Copy the token it prints.

4. In your app, set:

   | Setting | Value |
   |---------|-------|
   | Base URL | http://127.0.0.1:4141/v1 |
   | API key | the token from step 3 |
   | Model | gpt-6.1-sol |

The token logs in as you. Keep it private, and do not paste it into an AI chat.

 Let an AI agent do the setup

Paste this into a coding agent. It stops before the token step, so your token stays with you:


Set up OpenMatthew on this computer. Repo: https://github.com/ChindanaiNaKub/OpenMatthew

1. Clone it, run npm install, then start npm run serve in the background.
2. Check that http://127.0.0.1:4141/v1/models returns a JSON model list.
3. Stop there. Tell me to run npm run creds myself. Do not ask me to paste my token into this chat.


 Connect your app

- Any OpenAI-compatible app: use the settings in step 4 above.
- Hermes Agent: in ~/.hermes/config.yaml, set provider: custom, base_url: http://127.0.0.1:4141/v1, and your token as api_key.

 OpenCode

OpenCode uses the plugin in this repo. The plugin starts its own local server, so you do not run npm run serve. You need OpenCode v2. Older v1 releases do not load the plugin.

1. Install the plugin. In your OpenCode config (~/.config/opencode/opencode.json), add it to plugins:

   json
   {
     "plugins": ["opencode-matthew-auth"]
   }
   

   To use it only in this repo, skip this step. The repo's opencode.json already loads it. Run opencode from the repo folder.

2. Start OpenCode and run /connect. Choose CMU Matthew AI, then Login with CMU Account.

3. A browser opens to matthew.cmu.ac.th. Log in. Press F12, open the Console tab, and run copy(localStorage.user).

4. Return to OpenCode and paste the result. The login is saved. Your token stays on your computer.

5. Pick a model from CMU Matthew AI, such as gpt-6.1-sol. Remember that Matthew answers with your default assistant. See Models.
