vt-dsh-plugin · DeepSeek Harness 插件总集

一组面向 DeepSeek Harness（DSH）的插件，放在同一个仓库里统一维护、统一发布。
每个插件目录都是一个独立发布的 npm 包，可以单独安装、单独升级。
仓库同时维护一份市场索引：除了这里的插件，还收录我在用的第三方插件，
方便别人直接复刻这套配置。

 安装

插件装进某个 profile 后必须重启 dsh，刷新页面不生效。

 插件市场（推荐，有更新提示）

在「插件 → 发现 → 添加索引源」里填入市场索引地址：


https://vontean.github.io/vt-dsh-plugin/index.json


市场属于实验特性：第一次使用要先在插件页开启 Custom plugin markets。索引地址必须是 https，
不能带 query 或 fragment。添加后按分类浏览，点安装即可；有新版时市场会显示「有更新」，
更新动作等于卸载再安装。

 npm

bash
dsh plugin --profile  add dsh-vt-quote-bar@1.0.1


npm 通道要等该版本真的发布到 npm 之后可用（用 npm view @ 能查到即可）。
还没发到 npm 时，请用市场索引或 Release tarball：三条通道发出去的是同一份构建。

刚发完的那几分钟，本地 npm view 可能返回 404（registry 传播与本地缓存都还没跟上），
不要据此判断发布失败、更不要重发：直接看 Release 里 + @ 那行，或隔几分钟
再查 https://registry.npmjs.org//。同一个版本号重发会被 npm 拒绝。

 Release tarball

到 Releases 下载对应插件的 .tgz，然后：

bash
dsh plugin --profile  add /绝对路径/dsh-vt-quote-bar-1.0.1.tgz


 Git 子目录（不使用市场与 npm 时的兜底）

bash
dsh plugin --profile  add 'git+https://github.com/Vontean/vt-dsh-plugin.git&path:/plugins/vt-quote-bar'


市场索引里的 git 来源就是这种 spec：commit 固定，不会漂移。仓库里提交了构建产物，安装时不执行构建脚本。

 支持的 DSH 版本

本仓库的每个插件在 package.json 的 engines.dsh 里声明兼容范围，目前统一为
=0.2.1-rc.5 =0.2.0-rc.1 =0.0.1；dsh-better-sidebar、dsh-ego-browser、dsh-pet 没有声明 engines.dsh，等于不设门槛，
