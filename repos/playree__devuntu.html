Devuntu






English | 日本語

Website: https://playree.github.io/devuntu/

 [!NOTE]
 Self-hosted kanban & ticket management with a built-in MCP server, where AI agents (Claude Code / Codex / OpenCode) work on your tickets, with humans approving plans and reports.
 English README: README.en.md (overview and quick start).
 The detailed documentation is available in Japanese only.

Devuntu は、かんばん形式のボード/チケット管理を中心に、
カレンダー連携、メール/Slack/Webプッシュ通知、MCP/AIエージェント連携、リモート実行などを備えた
セルフホスト型のプロジェクト管理ツールです。

特徴

- AI エージェントが担当者になる  
  Claude Code / Codex / OpenCode を担当者にして、承認者がエージェントモード(プラン先行 / 自動実行)を選ぶと、就寝中でも担当チケットを処理します。プランや報告書はチケットに残り、人が承認・差し戻しできます
- MCP サーバーを内蔵  
  普段使いの AI ツールから、自分の権限でチケットの起票・更新・報告ができます。ボードごとの前提(リポジトリや規約)も AI へ届きます
- compose.yaml 1つでセルフホスト  
  Docker Compose で導入でき、データは手元に置けます。MIT ライセンスで、人数による制限や課金はありません

すぐに試す(詳細は導入の流れ)

sh
mkdir devuntu && cd devuntu
curl -fsSLO https://raw.githubusercontent.com/playree/devuntu/stable/compose.yaml
docker compose run --rm tools setup-env    設定ファイルを対話生成
docker compose up -d --wait
 起動したらすぐ、ブラウザで /start を開いて最初の管理者を登録
 (ユーザーが居ない間は、この画面に届く人なら誰でも登録できる)

 できること

- かんばんとチケット管理(ボード、タグ、担当者、優先度、期日、コメント、メンション)
  - 親子・関連チケット、受け入れ条件、ボードごとのチケットテンプレート、変更履歴
  - 本文・コメントへのファイルの添付(チケットごとに添付の一覧を表示)
  - 本文・コメントは Markdown で書け、mermaid の図・コードの色付け・GitHub 形式の注意書き・脚注も表示できる
  - かんばん・一覧で、指定したチケットの子・関連チケットに絞り込める
  - チケット全体やプラン/報告書を PDF / HTML に出力できる
- Googleカレンダー連携と、認証不要な公開URLでの空き時間共有
- メンションや担当者変更、AIエージェントの実行結果、マージによる自動完了の保留、期日のリマインドのメール / Slack DM / Webプッシュ通知
  - チームボードは Slack チャンネルへも流せる(チケットの作成・完了、担当者の変更、エージェントの実行結果、マージによる自動完了の保留、アナウンス)
- MCPサーバーとして、AIエージェントから自分の権限でチケットを操作できる
- AIエージェントを担当者として登録でき、担当チケットをAIエージェントが自動的に処理する仕組みを構築できる(現状はClaude・Codex・OpenCodeに対応)
  - 大きなチケットはエージェントが子チケットの起票案を出し、承認すると子を順番どおりに自動で処理する(タスク分割)
  - 対象リポジトリや規約など、ボード共通の前提を「AI向けコンテキスト」として MCP クライアント・エージェントへ届ける
  - AI が作業で得た知見をボードの「メモリ」に、利用者が管理する知識を「ナレッジ」に溜め、メンバーと AI で共有する(索引だけを渡し、本文は必要なときに読ませる)
- GitHub / GitLab(セルフホスト版を含む)のブランチ / プルリクエスト / コミットをチケットに紐付け、PR の状態と CI の結果を表示。  
  マージでチケットを自動で完了にでき(未達の受け入れ条件が残っていれば保留)、CI の失敗や PR / MR のレビュー指摘でエージェントへ自動で差し戻せる
- 定義済みの処理をリモートのサーバーで実行し、出力をリアルタイムで確認できる
- メールOTP、パスキー認証、Googleログイン
- OAuthプロバイダとして利用できる
- 日本語 / 英語の表示切り替え

 開発の背景

- シンプルなチケット＆かんばんボードが欲しい
- Claude Codeを利用してプラン作成→実装と進めた際に、プランや実装結果を残しておきたい
- 就寝中の時間を有効活用したい（就寝中にClaude Codeでチケットを処理させる）
- 各種通知はSlackに欲しい
- GitHub / GitLab(セルフホスト)と連携させたい
- 自分の空き時間を共有したい
- 定型処理をツール化したい

など、個人・少数チーム開発をするうえで、自分が開発する上で欲しいと思った機能を形にしたものになります。  
なので、連携機能(サービス)も自分が普段使っているものがメインとなっています。(Claude / GitHub / GitLab / Slack / Googleアカウント)
