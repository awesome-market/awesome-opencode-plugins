GLM Proxy for AutoClaw

GLM Proxy (glmproxy) is a local Node.js API proxy for AutoClaw's Zhipu AI GLM models. It exposes OpenAI-compatible Chat Completions and Anthropic Messages APIs, so you can use AutoClaw models with Claude Code, Cursor, Continue, OpenCode, LiteLLM, and OpenAI or Anthropic SDKs on Windows, macOS, and Linux.

v3.3.0. One CLI, two API formats, zero npm dependencies.

---

 Quick Start

bash
npm i -g glmproxy
glmproxy


That's it, an interactive menu walks you through format, port, and key. Prefer flags?

bash
glmproxy --anthropic --port 3001 --key mykey


Then point any OpenAI-compatible tool at http://127.0.0.1:18791/v1, or any Anthropic-compatible tool at http://127.0.0.1:18792. Default key is mewmew (see Integrations below for exact per-tool setup).

You need: AutoClaw installed, running, and logged in:
- Windows / macOS / Linux: AutoClaw 1.x reads the plaintext request-headers.json; AutoClaw 2.x (Electron) writes an encrypted vault and the proxy decrypts it itself — Windows via DPAPI, macOS via the login Keychain, Linux via the Secret Service / GNOME Keyring. Either way auth is automatic — no manual token copying. Node.js 18+ required on all platforms.
- Linux: For Linux TLS compatibility matching AutoClaw's Electron fingerprint, ensure curl_cffi is installed (pip install curl_cffi).

---

 Integrations

 Claude Code CLI & Anthropic API

Add to ~/.claude/settings.json:

json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:18792",
    "ANTHROPIC_AUTH_TOKEN": "mewmew"
  }
}


Or let the proxy do it for you: run glmproxy, pick Anthropic format, and choose Launch Claude Code with \. The launcher writes a settings file into the proxy's state dir, passes it through claude --settings (feature-detected — older clients fall back to environment-only routing), waits for the gateway to answer /healthz, and then hands your terminal to the interactive client. The gateway stays up when Claude Code exits; GLMP_CLAUDE_BIN points the launcher at a different binary if claude is not on PATH.

 Supported Modes & Known Caveats:
- Claude Agent SDK & Direct API: Fully supported. Direct /v1/messages calls, streaming SSE deltas, thinking blocks, and tool use execute cleanly without restrictions.
- Claude Code CLI (interactive and print mode): Works. On AutoClaw 2.x the upstream's system-prompt gate rejects any prompt carrying a foreign harness signature, and Claude Code's own system prompt names itself — the proxy's identity guard (GLMP_FOREIGN_IDENTITY_GUARD, on by default) rewrites those phrases (You are Claude Code, built on Anthropic's Claude Agent SDK, …) before forwarding. Measured 2026-10-14 against Claude Code 2.1.296 with the client's own captured system block. Print mode:
  bash
  claude -p "Explain the codebase architecture"
