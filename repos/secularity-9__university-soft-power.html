README

大学软实力 · University Soft Power

 一份可装进 AI 的「大学沟通与答辩作战手册」。
 基于依力《高效沟通领导能力》课程讲义整理，核心内容零删减，另补充少量通用表达 / 谈判 / 可视化 / 面试方法。

一句话内核：任何沟通场景只有一个问题——对方想要什么，我以他能理解、能接受的方式给他。

---

 这是什么

一个 Claude Skill / Agent Skill 格式的技能包。装上它，AI 在你准备竞选演讲、学术答辩、保研复试、转专业/二次选拔面试、辩论赛、谈判说服、拒绝别人时，会按这套方法论给你可直接执行的稿子、PPT 大纲和问答预演——而不是泛泛的"多练习、要自信"。

覆盖六类场景：

| 场景 | 你会在什么时候用到 |
|---|---|
| 通用沟通 | 说话、拒绝、被问到不会的问题 |
| 演讲 | 竞选班委、竞选项目负责人、自我介绍、任何上台讲话 |
| 辩论 | 辩论赛、思政课辩论、小组讨论里的观点交锋 |
| 说服 | 导师邮件、拉赞助、找合作、砍价、转专业争取资源 |
| 答辩 | 课程 presentation、竞赛答辩、毕业答辩、保研复试 |
| 心法 | 迷茫、怕失败、自我怀疑、不敢上台 |

 安装

 方式一：作为 DSH / Claude Code Skill 安装（推荐）

把 SKILL.md 放到你的 skills 目录：

bash
 DSH（本机）
~/.agents/skills/university-soft-power/SKILL.md

 Claude Code
~/.claude/skills/university-soft-power/SKILL.md


装好后，AI 在遇到上述场景时会自动加载；也可以直接说：

 用 university-soft-power 帮我准备明天的小组答辩。

 方式二：直接当文档读

不想装也行——SKILL.md 本身就是一份完整的手册，从头读到尾就是一门课的文字版。

 方式三：配合 AI 对话使用

把 SKILL.md 全文贴给任意 AI 对话框，然后提出你的具体场景（专业、时长、评委是谁、PPT 几页），让它按 §8.5 的上台前清单逐项帮你过。

 核心内容速览

第一原理：共情。 以对方的理解能力为基础，对方怎么期待这句话，就怎么输出。所有场景（演讲/辩论/说服/答辩）都只是这一条的不同外壳。

注意力是稀缺资源。 不重要的内容快讲（大脑会自动忽略），你希望被记住的句子放慢、停顿、只说一次——"Attention is all you need"。

四种反模式： 用说服的心态去辩论、用辩论的心态去演讲、用自我感动的心态去答辩、用自我表达的心态去沟通。

答辩公式： 80% 演讲 + 20% 说服 + 0% 辩论。你才是主角，PPT 不是；最后一页放大纲，不写"谢谢老师"；提问只答不辩，除非事实有出入。

心态关： "我就做了这么点东西，但我尽力了，我来讲给你们听。"——先自己信，别人才会给高分。
