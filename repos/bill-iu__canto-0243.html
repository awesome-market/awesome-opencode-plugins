Canto-0243


  繁體中文 · 简体中文 · English


填粵語歌詞，通常一係就「唔知有咩字」，一係就要喺同音、押韻、近義之間快速換字，又要對準 0243 與粵拼讀音。傳統做法係喺詞典、韻書、近義表之間搵嚟搵去，手動試「呢個位可唔可以換另一個字」——慢，而且容易漏咗好多可以用嘅字。0243.hk 已經算係近年最好用嘅粵語填詞查找網站，但係偶爾都會 502 Bad Gateway 上唔到；或者喺搵字嘅時候無限輪迴 load 唔到；又或者你想搵某個字但係佢冇嗰個功能——呢啲時候就會拖慢你嘅進度。

Canto-0243（ONE·搵·韻）係我用幾個唔同AI AGENT(Cursor, Codex, Grok Build, Github Copilot）開發嘅一個離線粵語填詞查找工作台：用 394052／02493 數字碼、粵拼、韻母／聲母規則與 近義／反義關係，喺幾秒內列出符合條件嘅詞條。頂欄 0243搜尋模式 有三檔：0243模式（鬆）、02493模式（緊）、394052模式（六聲，三聲 4／五聲 5 分明）。例如打 23就 搵同調又同「就」同韻嘅尾字；打 香港= 搵同「香港」同韻嘅候選詞；打 ZP 會自動切換 394052模式做平仄串列；打 ~開心 或切換近反義模式搵近義/反義詞；打 ~~／!! 搵填詞常用嘅二字近義／反義複合詞。完成首次下載及啟動設定後，詞庫與近反義資料都儲存喺本地，可以離線使用。

授權：整包（程式、lyrics.db、words-lexicon.json）依 Canto-0243 License（CC BY-NC-SA 4.0 + 附加條款；開源）。第三方上游資料見 THIRD_PARTY_NOTICES.md。  
技術棧：FastAPI · SQLAlchemy · SQLite（離線單機）· React + Vite（PWA 與 Desktop 共用介面；Service Worker / Web App Manifest；PWA 離線資料庫以 OPFS / wa-sqlite 提供）

 功能

詞語與讀音分開排序 — 已為全部 81,729 個自建字面建立詞語常用度分級，經覆核退回 2,051 個冷僻表達。日常生活、通用書面與填詞表達按常用度排列，讀音另按整詞語境及讀音分級排序。

詞語排序參考既有 Essay 詞頻與 TUBELEX 中文字幕觀測；資料不足時另記 AI 情境判斷，已完成 24,693 項。AI 判斷並非實測詞頻，原始觀測與判斷依據分開留檔。詳見常用度與退回紀錄及自建詞庫讀音分級。

 0243搜尋三檔：0243模式 mode=m1（鬆檔等價）· 02493模式 mode=m2（僅 4↔5 鬆檔）· 394052模式 mode=m3（六聲碼逐位精確；詞庫存儲用 394052，三聲 4、五聲 5 分明）。
 多種查詢語法：純漢字 · 純數字 · 粵拼查詢 · 平仄串列（PZ／ZP，自動切 m3）· 加號錨（23+好=）· 韻／聲錨（就=）· 串列韻／聲錨 · 四字部分韻／聲錨（窮?潦倒=）· 前綴通配等號 · 整詞等號／碼夾。
 近反義：近反義模式 mode=syn 全欄 UI（不收粵拼）；或在 0243搜尋三檔下 ~詞／!詞、反義複合 !!、近義複合 ~~（會記住離開近反義前嘅搜尋檔）。

 快速開始

選一種開始使用：

- Canto-0243 手機版：直接開啟 https://bill-iu.github.io/Canto-0243/ ，加到主畫面後完全離線可用。頂欄有「搜尋教學」。

- Desktop 離線版：從 Releases 下載解壓。Windows 雙擊 Canto-0243.exe；macOS 雙擊 Canto-0243.app（Gatekeeper 只對 .app 右鍵打開／仍要開啟一次）。首次需網路。

更新至本版：PWA 重新開啟並完成詞庫更新；桌面版下載最新完整套件，再開啟新版程式。
