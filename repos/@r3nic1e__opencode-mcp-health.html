README

opencode-plugins

Plugins for OpenCode 2. Each directory under packages/ is one npm package.

| Package | What it does | Parts |
|---|---|---|
| @r3nic1e/opencode-evidence | Records tool results, adds citation handles such as [E17], and adds a TUI browser for them. | server, TUI, RPC |
| @r3nic1e/opencode-pr-tracker | Tracks pull requests created through the GitHub MCP and shows their status in the session sidebar. | server, TUI, RPC |
| @r3nic1e/opencode-mcp-args | Shows MCP tool arguments above the permission prompt. | TUI only |
| @r3nic1e/opencode-mcp-health | Tells the model which MCP servers are down or need sign-in, and which local references are missing. | server |
| @r3nic1e/opencode-github-guard | Blocks remote git, gh, and api.github.com calls in a sandbox that cannot make them, and tells the model what to use instead. | server |
| @r3nic1e/opencode-litellm-cache-scrub | Removes Anthropic prompt-cache fields from requests to gateways that reject them. | server |
| @r3nic1e/opencode-meridian-quota | Serves Meridian quota to @slkiser/opencode-quota. | server |
| @r3nic1e/opencode-openai-decisions | Adds an openai_decisions tool for the OpenAI Decisions API. | server |
| @r3nic1e/opencode-remove-tools | Removes configured tools, including built-in ones such as session_move, from every session. | server |

 Install

Add server plugins to plugins in opencode.json(c). Pin a version, and use the object form to pass options:

jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "@r3nic1e/opencode-evidence@0.1.3",
    {
      "package": "@r3nic1e/opencode-openai-decisions@0.1.1",
      "options": { "endpoint": "https://api.openai.com/v1/decisions", "providerID": "openai-api" },
    },
  ],
}


A package with only a TUI part, such as @r3nic1e/opencode-mcp-args, goes in plugins in cli.json instead.

Each release also has a Git tag @, so you can install from GitHub without npm:

sh
opencode plugin add 'github:r3nic1e/opencode-pluginsevidence@0.1.3::path:packages/evidence'


 Development

Server and RPC parts ship as TypeScript source, and OpenCode loads them directly.

A TUI part needs a build step. OpenCode compiles TUI JSX with the OpenTUI Solid transform, but that transform skips files under node_modules, where npm installs plugins. Without it, the JSX loses reactivity and the plugin renders nothing. So each package exports ./tui as dist/tui.js, which scripts/build-tui.mjs compiles from src/tui.tsx. The file is committed so that Git installs work, and prepack rebuilds it on publish.

After you edit a src/tui.tsx, run npm run build and commit dist/tui.js. npm test fails if it is stale.

sh
npm ci
npm run build
npm run typecheck
npm test


 Release

1. Bump version in packages//package.json and merge the change.
2. Push the tag @ on that commit, for example evidence@0.2.0.
