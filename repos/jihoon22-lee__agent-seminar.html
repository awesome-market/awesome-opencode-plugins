agent-seminar

AI 에이전트 확장하기: 스킬, MCP, 플러그인 (opencode 편)

코딩 에이전트 opencode에 팀의 지식과 시스템, 규칙을 붙이는 세 가지 방법을 다룬 60분 세미나 자료입니다.
발표 슬라이드와 글로 읽는 가이드, 그리고 직접 실행해 볼 수 있는 예제 52개가 들어 있습니다.

- 발표 자료: https://jihoon22-lee.github.io/agent-seminar/ (브라우저에서 바로 열립니다. ? 키로 단축키를 볼 수 있습니다)
- 가이드: docs/guide
- 예제 목록: examples/README.md

모든 내용은 opencode 1.19.5에서 직접 실행해 확인했습니다. 모든 예제의 check.py를 Windows(PowerShell 5.1)와 Linux 양쪽에서 실행해 통과시켰습니다. 도구가 없어 건너뛴 부분과 확인하지 못한 부분은 각 README에 "미검증"으로 적었습니다.

 한 줄 요약

| 확장 | 한 줄 설명 | 이럴 때 |
|---|---|---|
| 스킬 | 모델이 필요할 때 꺼내 읽는 업무 매뉴얼 (SKILL.md) | 모델이 알아야 할 절차나 지식: 커밋 규칙, 리뷰 기준, 분석 순서 |
| MCP | 에이전트 바깥의 프로그램이 도구를 제공하는 표준 방식 | 에이전트 밖의 시스템에 닿아야 할 때: 티켓 DB, 위키, 모니터링 |
| 플러그인 | 도구 실행 앞뒤에 끼어드는 코드 | 모델 판단과 상관없이 항상 일어나야 할 때: 차단, 감사 로그, 알림 |

셋을 켜고 끄는 곳은 opencode.json입니다. 개념 설명은 가이드 0. 개념에서 시작하세요.

 준비물

- opencode 1.19.5 (opencode --version으로 확인)
- Python 3.10 이상: 예제 스크립트와 Python MCP 서버는 표준 라이브러리만 씁니다. M2 예제만 mcp 패키지를 설치합니다.
- git 2.28 이상: 예제 준비 스크립트(prepare.py)가 git init -b를 씁니다.
- Node/npm (선택): 플러그인 예제의 단위 테스트와 패키지 미러 지정(npm config)에 씁니다. npm이 없으면 %USERPROFILE%\.npmrc(Linux ~/.npmrc) 파일에 registry= 한 줄을 직접 써도 됩니다. M10(Node 서버)과 M11(npx로 파일 서버)은 Node 18 이상이 필요합니다. 없으면 두 예제의 해당 부분은 건너뜁니다(check.py가 경고만 냅니다).
- uv (선택): M11(uvx로 시간 서버)과 M12(uvx 배포 경로)에 씁니다. 없으면 uvx를 쓰는 부분만 건너뜁니다. M12의 python -m 기본 경로는 uv가 필요 없습니다.
- Rust(cargo) (선택): M14(실행 파일 하나로 된 서버)를 직접 빌드할 때만 씁니다. 없으면 M14의 빌드와 검사를 건너뜁니다.
- 모델: 평소 쓰는 모델을 그대로 쓰면 됩니다. 설정된 모델이 없다면 무료 모델 opencode/big-pickle을 -m으로 지정할 수 있습니다.

기본 경로의 예제는 인터넷 없이 돕니다. 다만 M10, M11, M12, M14의 설치 단계(npm install, npx, uvx, cargo build)는 패키지 레지스트리나 미러가 필요하고, 닿지 않으면 check.py는 그 검사를 경고와 함께 건너뜁니다.
또한 .opencode/ 폴더가 있는 예제는 시작할 때 opencode가 npm 패키지 @opencode-ai/plugin을 설치하려고 합니다.
인터넷이 막힌 환경이라면 먼저 npm 패키지 미러를 지정하세요. 레지스트리에 닿지 않으면 플러그인이 있는 예제(.opencode/plugins/)는 시작할 때마다 약 70초(새 환경의 첫 시작은 약 130초) 멈추고, 이 패키지를 쓰는 플러그인 도구(P6, X1-c)는 조용히 사라집니다. 스킬만 있는 예제는 설치를 시도하지만 눈에 띄게 멈추지는 않았습니다.

powershell
npm config set registry https:///      %USERPROFILE%\.npmrc 에 저장됩니다


미러에 닿으면 첫 시작이 10초 안팎, 그다음부터는 1초 안팎입니다. 자세한 내용은 P6 README에 있습니다.

 시작하기

PowerShell:

powershell
git clone https://github.com/jihoon22-lee/agent-seminar
cd agent-seminar\examples\01-skills\s1a-commit-message
python prepare.py       실습용 git 저장소 sandbox\ 를 만듭니다
cd sandbox
opencode


Linux bash:

bash
git clone https://github.com/jihoon22-lee/agent-seminar
cd agent-seminar/examples/01-skills/s1a-commit-message
python3 prepare.py      실습용 git 저장소 sandbox/ 를 만듭니다
cd sandbox
opencode


예제 폴더 하나하나가 독립된 opencode 프로젝트입니다. 폴더에 들어가서 opencode를 실행하면 그 예제의 설정, 스킬, 플러그인만 적용됩니다.
prepare.py가 있는 예제는 먼저 실행하세요. git 저장소가 필요한 예제는 sandbox/에 실습용 저장소를 만들고, 그 안에서 opencode를 실행합니다.
각 README는 같은 순서로 되어 있습니다: 무엇을 보여 주나, 실무에서는, 파일 구성, 따라 하기, 기대 결과, 동작 원리, 직접 바꿔 보기, 주의할 점.

Linux에서 python 명령이 없으면 예제 설정과 명령의 python을 python3로 바꾸세요.
