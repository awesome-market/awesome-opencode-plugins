Video skills for coding agents: films drawn in code.

Filmsmith is an agent skill that makes videos with nothing but code: every picture is drawn with HTML, canvas and GSAP on HyperFrames, and every film is rendered and measured by scripts. One skill, skills/filmsmith/, two pipelines off one library of bricks. It runs in any coding agent that can use a shell.

| Pipeline | Makes |
|---|---|
| Launch films | Short music-driven films for a technical product — launches, teasers, showreels, data stories — composed from bricks with seventeen styles as recipes, on-screen text in English or Chinese, no voice-over |
| Teach films | Explainer films that teach one technical idea to developers who know the basics, with a Chinese voice-over and Chinese or English on-screen text |

 Install

With the skills CLI, which lists the skills in this repository and asks which ones to install and for which agents:

bash
npx skills add coder-xieshijie/filmsmith


Or clone the repository once and link the skills you want into your agent's skills folder:

bash
git clone https://github.com/coder-xieshijie/filmsmith.git
ln -s "$PWD/filmsmith/skills/filmsmith" /filmsmith


git pull in the clone updates the linked skill.

 Launch films

Film your code, brick by brick. The launch pipeline (pipelines/launch.md) makes short technical films — launches, teasers, showreels, data stories, explainers — with every frame drawn in code and every sound synthesised in code. A film is composed from bricks (motions, scenes, props, looks, sounds and story arcs) with two or three styles as references and one look of its own; when one style fits exactly, its template runs as it ships. On-screen text is English or Chinese, chosen from your material.

!Sixteen of the styles

 Seventeen styles

Each style is a recipe — one look, the bricks it recommends for each part of the story, what a film in it must not do — and a template that renders its example film, with palette presets and one form variant. Every preview below is six seconds of an existing demo made with the skill itself (28–46 s; Stream's is 92 s). The first ten full films are on YouTube, with MP4 downloads in the v0.1.0 release; uploads for the six real-asset demos and Stream are pending.

The first ten demos use fictional products except Tally, which counts the real Python PEP index. Handset, Exhibit and Dossier demonstrate real launch pages, charts and product UI captured on October 20, 2026; Strip, Split and Scroll use Filmsmith's own films, code and repository captures from October 21. Stream's demo is a made-up agent desk, Skein, in an English and a Chinese version. Figures, offers and the ten-style README visible in these films belong to those source snapshots. The overview images show the first sixteen styles (Stream is not in them yet); the preserved demos may use earlier palette presets.
