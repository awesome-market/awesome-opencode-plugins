NeXgen Engine


  
    
    
  



  
  
  
  
  



  🇮🇹 Italiano · Quick start · How it compares · Architecture · Changelog


Make the AI subscriptions you already pay for work as one team, across all your machines.

NeXgen Engine is one Git repository that configures Claude Code, Codex, OpenCode, Antigravity and OpenClaw from a single source, and keeps them aligned on every PC you use.

 What you get

- More out of the flat plans. nexgen quota reads what the harnesses on this machine already wrote about their own usage: what each plan has used, the percentage where the provider publishes one, the reset time when it is known, and how old the reading is. A window it cannot measure from here says so instead of showing a guess. If you declare a fallback chain in quota.yaml, nexgen openclaw setup writes it into the OpenClaw agents the engine creates: once the last reading is past the line, 95% by default, the next turn starts on the next model instead of running into a spent plan. See quota.md.

- Models from different vendors on the same job. council convenes the CLIs you already have as seats, each on its own model, to brainstorm, attack a plan or review code written by another vendor. It is opt-in: with no seats.yaml there is no Council. See council.md. A supervised task goes further: a frontier model writes the brief, an executor carries it out in a window of its own harness, and the engine keeps the files, the cost register and the gates that run before anyone reviews a diff. That part is a preview, and the docs say what the gates do not guarantee. See supervision.md.

- Connectors and skills configured once. One MCP manifest and one skills manifest in the Vault are rendered into each CLI's own native format by nexgen sync. The merge is additive, so a server you added by hand survives. Claude Desktop is the exception: it gets only the connectors you opt into with desktop_allow: true, and only for read-only servers. See sync-contract.md and what-gets-written.md.

- Several PCs from one source. nexgen sync applies the configuration on each machine and nexgen doctor reports what drifted. Secrets live in one age-encrypted file with a key per enrolled machine, and OAuth refresh tokens are stored per host, so a token that rotates on one PC does not break another. See roles.md.

- Memory you can read and diff. The KnowledgeVault is Markdown in Git: notes, decisions and project state. Writes go through the Vault MCP, which checks the note or section hash first and refuses a stale replacement. See architecture-contract.md.

- One harness for everything, if you want it. OpenClaw is the engine's official harness: a web panel and a phone app over the subscriptions you already pay for, an agent squad declared in squad.yaml, one node per PC and channel bindings that route a chat to the right agent. See openclaw.md and squad.md.

nexgen info     dashboard: engine version, runtimes, modules, installed MCP servers and skills, secrets
