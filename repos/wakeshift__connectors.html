Wakeshift connectors

The open-source parts of Wakeshift that run on your machine or inside your agent. Wakeshift wakes AI agents (Claude Code, Codex, Cursor and others) when something happens in the apps they're connected to; this is the code that does it on your side, published so you can read exactly what it does.

| Path | What it is |
| --- | --- |
| cmd/wakeshift-connector | The wakeshift program: the hooks and connectors that let Wakeshift wake an agent, and its install and uninstall commands. |
| internal/ | The packages compiled into it: reading Wakeshift's signed beacons from tool results, holding a conversation's stream link, framing messages as outside information, each harness's setup. |
| plugins/hermes | Wakeshift's plugin for Hermes Agent (Python). |
| plugins/openclaw | Wakeshift's plugin for OpenClaw (TypeScript), published to npm as @wakeshift/openclaw with provenance by .github/workflows/npm.yml, from each release. |
| sdk/cli | wakeshift-cli, the command line for developers adding Wakeshift events to an MCP server: it makes the app's key on their machine, creates the app through a console link they confirm, and verifies the server wakes agents. Published to npm as @wakeshift/cli with provenance by .github/workflows/cli.yml, when a cli-v tag is pushed. |

You don't install this by hand: when an agent first needs it, Wakeshift's tool result asks the agent to run a one-time install, and the agent asks you first. Agents says what the install changes for each agent and how to undo it.

Building an app? Use the SDKs: TypeScript, Go and Python.

 Building and testing

sh
go build -o wakeshift ./cmd/wakeshift-connector
go test ./...

cd plugins/hermes && uv run --no-project --with cryptography python -m unittest discover -s tests -t tests
cd plugins/openclaw && npm ci && npm run lint && npm test
cd sdk/cli && npm ci && npm run lint && npm test


To stamp a version: go build -ldflags "-X github.com/wakeshift/connectors/internal/version.Version=" ./cmd/wakeshift-connector.

The Hermes plugin's and the CLI's end-to-end tests need a running Wakeshift, so they run in Wakeshift's own repository.

 Contributing and security

This repository is generated from Wakeshift's main repository. Pull requests are welcome: we apply them there and publish the result. Each commit here says which commit it came from (.source-commit); see CONTRIBUTING. Report a security problem privately to support@wakeshift.ai, not in an issue (SECURITY).
