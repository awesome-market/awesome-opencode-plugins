 The lessons

| | Lesson | What you can do |
|---|---|---|
|  | How a turbofan worksCFM56-7B-class two-spool high-bypass engine, 8 steps | Start the engine, then throttle it, light the combustor and push the compressor into surge. A live Brayton-cycle model drives the spools, temperatures and thrust. |
|  | One LLM token on CPU + GPUFrom the CPU core to HBM stacks and the KV cache, 9 steps | Run prefill and decode, and see where the roofline caps you. Watch KV-cache pages fill the HBM stacks. |
|  | How a mechanical watch worksETA 2824 / NH35-class automatic movement, 7 steps | Wind the mainspring, follow the gear train to the Swiss lever escapement, change the beat rate and watch the timegrapher trace drift as the power reserve runs down. |
|  | How an EV motor + inverter worksModel 3-class rear drive unit: hairpin IPM motor, SiC inverter, 7 steps | Push the pedal and sweep the speed: a live field-oriented-control (dq) model moves the current vector, shows the voltage-limit ellipse closing in (field weakening), draws the torque–speed envelope and flips power flow into regen. |

Every lesson:
- is one self-contained index.html, with three.js and fonts from a CDN and no build tools;
- models real parts from public drawings and photos, not placeholder shapes. Each one is checked side by side against reference photos (see explainers//fidelity/REVIEW.md);
- runs a linked simulator, so changing a control changes the 3D scene, the readouts and the charts together;
- is bilingual: English by default, with 中文 from the toggle or ?lang=zh (remembered in localStorage);
- supports deep links: ?step=3 opens a given step, and ?quality=low suits weak GPUs.

 Run locally

bash
git clone https://github.com/tyyy-z/mechanism-explainer
cd mechanism-explainer
python3 -m http.server 8000       then open http://localhost:8000


Each lesson can also be opened straight from disk (explainers//index.html).

 Rebuild a lesson

Sources are in explainers//src/. build.py inlines them into index.html:

bash
cd explainers/turbofan && python3 build.py


 Layout


index.html              hub (English default, 中文 toggle)
assets/                 hub css/js, posters, preview loops, step thumbnails, photos
explainers//      index.html · build.py · src/ · refs/REFS.md · fidelity/REVIEW.md + _sbs.webp
skill/SKILL.md          the agent skill that builds these (install: skill/README.md)
docs/                   README banner and GIFs


 The skill

skill/SKILL.md is the agent skill behind these lessons, covering:
- concept lessons;
- rebuilding a reference video as a live 3D app;
- deep device lessons from public sources;
- the real-device fidelity standard;
- bilingual UI;
- packaging lessons into a hub like this one.

Install notes are in skill/README.md.
