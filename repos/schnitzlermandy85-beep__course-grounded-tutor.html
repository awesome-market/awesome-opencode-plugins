Course-Grounded Tutor

 帮助中小学到大学学生自主学习新知识的全学科私人老师



!Focus
!Teaching
!Context

工作原理 · 安装 · 开始使用 · 项目结构 · 设计边界



---

course-grounded-tutor 面向小学、初中、高中和大学阶段的学生，帮助他们自主学习各学科的新知识，目标是成为能独立承担授课任务的私人老师。即使没有学过、没有教材、还提不出具体问题，也能从合适的起点开始：先把学生提出的全部问题和相互关系梳理清楚，再判断哪里适合文字、聊天图像或交互 HTML，最后按合适的深度讲透。既能一步步带着学，也能按要求给出完整讲解；文字紧凑，关键推理不省略。

它可以直接处理普通学习问题，也能结合 PPTX、PDF、DOCX、截图、课程文件夹和 Markdown 笔记进行基于课程证据的逐点教学。

 让学生从“没学过、不知道从哪开始”，走到“能理解、能运用、知道下一步怎么学”。

 为什么需要它

普通问答往往从“生成答案”开始；这个 Skill 从“学习诊断”开始。

| 常见问题 | Course-Grounded Tutor 的处理方式 |
| --- | --- |
| 不知道问题属于哪个知识点 | 先定位学科 → 模块 → 子主题 → 核心概念 |
| 看得懂例题，自己不会做 | 判断缺的是识别线索、方法选择还是独立执行 |
| 被公式或符号卡住 | 先解释对象、符号和关系，再进入推导 |
| 答案错了但不知道错在哪 | 区分记号、概念、方法、推理和迁移错误 |
| “还是没懂” | 换表示、降难度、缩小到最早的阻塞点 |
| 一次讲太多 | 控制认知负荷，只推进当前最有价值的一步 |
| 想跨对话继续学习 | 生成可见、可复制的 Learning State Card |

 工作原理

!Course-Grounded Tutor 完整工作流程

查看可编辑的 Mermaid 流程图源码

1. 梳理与定向：整理全部问题，了解基础与学习用途；备考意向未知时询问一次，确认备考后核实往年题。
2. 规划与授课：按需要构建领域知识地图、学习阶段和可执行安排，再选择文字、聊天图示或交互 HTML 开始教学。
3. 反馈与调整：自主学习按需练习，备考提供题目与解析；根据实际表现修复卡点、调整计划或进入下一步。

 核心能力

 自主学习新知识

- 只需说“我想学什么”，就能梳理主题、找到起点，并在第一轮开始讲解。
- 小学侧重具体事物和图像；初中连接现象与概念；高中加强方法与推理；大学按需要深入理论、证据和应用。
- 学段只用于初始判断，实际理解决定难度；大学生也可以从零开始，小学生也可以适当拓展。
- 没学过的知识先教，不先判定为“知识缺陷”；必要前置知识随用随补。
- 每个单元结束时指出一个自然的下一步，逐渐帮助学生独立解释、运用和判断。


 先梳理全貌，再诊断

- 先覆盖学生提出的全部问题，说明关联、依赖和讲解顺序。
- 再定位各部分的核心概念与卡点。
- 检查必要的前置知识，而不是假设学习者已经掌握。
- 区分词汇、概念、符号、步骤、推理、识别、迁移和误解等缺口。

 先询问学习目的，再进入备考分支

- 新学习目标开始时询问一次：“这次学习是为了准备考试，还是主要想学懂新知识？”已说明的偏好不重复询问。
- 确认备考后，补齐考试名称、科目与范围，优先分析提供的往年题；没有资料时查找可验证的公开真题。
- 根据实际查看的题目提炼考点、题型、方法线索和易错点，再给出代表性题目与解析。
- 明确标注真题、改编题和原创同类题；找不到真题时直接说明，不伪造年份、题号或来源。
- 默认题目后附考点、思路、解答和易错分析；学生想先做时暂不揭示答案。只要计划或概念讲解时，尊重其范围。

 相关领域学习规划

- 根据目标、现有基础和可用时间，整理领域知识地图、前置依赖和学习顺序。
- 每个阶段都给出具体内容、学习活动、可观察成果和预计投入，避免只有“基础—进阶—精通”的空框架。
- 安排今日第一步，检查任务量是否符合可用时间，并保留复习与调整空间。
- 时间未知时给出按学习单元安排的初稿，明确假设，不虚构完成日期。
- 学习反馈或时间变化后调整原计划；只要计划时，交付计划即可，不强制开始授课或测试。

 自适应教学

- 在零基础、标准、进阶和 Auto Mode 之间选择合适深度。
- 优先建立直觉，再给定义、符号、过程、证明和边界条件。
- 已掌握的内容自动压缩；真正薄弱的前置知识才局部修复。
- 学习者仍然困惑时更换表示方式，而不是原样重复。

 主动可视化与紧凑排版

- 静态关系优先用聊天内图示：时间线、因果图、句子标注、概念图、曲线等。
- 参数变化、状态切换或逐步演示适合交互 HTML；实际生成可打开的文件，并检查关键交互。
- 图像紧邻对应解释，明确“看哪里、改什么、说明什么”。
- 合并相关段落，减少碎标题和重复总结，保留必要推理与可读字号。

 教学闭环

- 使用复述、预测、识错或近迁移进行轻量理解检查。
- 在关键问题之后停下，给学习者真实的参与空间。
- 备考模式包含题目与解析；独立测试、批改和进阶判断按学生需要进入。
- 从一次解答中提炼可复用的问题识别与迁移模式。

 课程资料驱动

- 支持 .pptx、.pdf、.docx、图片和 Markdown 笔记。
- 区分课程原文与补充解释，保留页码、幻灯片或文件位置。
- 对公式、图表和结构密集内容保留视觉检查环节。
- 可使用 ingest_course_materials.py 生成适合教学的证据包。

 安装

 Codex

先克隆仓库：

bash
git clone https://github.com/schnitzlermandy85-beep/course-grounded-tutor.git


在 macOS / Linux 终端中，将整个目录复制到 Codex Skills 目录：

bash
mkdir -p ~/.codex/skills
cp -R ./course-grounded-tutor ~/.codex/skills/course-grounded-tutor


安装后开始一个新对话，让 Codex 重新发现该 Skill。

 如果目标目录已经存在，请先自行确认要更新哪些文件。不要在未检查本地修改的情况下直接覆盖。

 其他 Agent 环境

这是一个以 Markdown 指令和渐进式参考资料组成的 Agent Skill。其他支持项目级 instructions、skills 或自定义 system prompt 的环境可以手动适配，但是否会自动加载 references/、examples/ 和脚本取决于具体运行时。

 开始使用

无需记住固定命令，直接描述你的学习状态即可：

text
我知道导数的定义，但不理解为什么 x² 的导数是 2x。
请先判断我缺的是哪个概念，再一步一步讲。
