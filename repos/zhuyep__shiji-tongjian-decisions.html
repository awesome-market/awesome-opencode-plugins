 30 秒核源：前后对比

不克隆也能先看结果。助手随口说「出处：shiji-041，引文：君行令，臣行意。」看起来像有据；对着语料核过，关键字段如下（完整输出还含上下文与来源哈希）：

正确引文：

json
{
  "status": "exact",
  "requested_quote": "君行令，臣行意。",
  "source_quote": "君行令，臣行意。",
  "source": {
    "id": "shiji-041",
    "book": "史记",
    "volume": "卷四十一",
    "chapter": "越王勾践世家"
  },
  "char_start": 308,
  "char_end_exclusive": 316,
  "boundary": "只校验文本一致性，不证明历史真实性、因果关系或古今适用性"
}


把末字「意」改成「义」：

json
{
  "status": "not_found",
  "requested_quote": "君行令，臣行义。",
  "source_quote": null
}


exact 只表示和本地语料一致，不证明史实，也不证明能套用到你的处境。语料里没有就明说缺口，不编造。免克隆复现与完整对照：核源翻车→exact。第二源 shiji-055 /「留侯行少傅事。」也能 exact：第二源一键核源。只改标点不能冒充 exact：normalized_only≠exact。原文对、ID 绑错也不是 exact：错绑ID≠exact。克隆后的命令见离线核验一分钟上手。

 30 秒判断值不值得

- 引文可离线核验；找不到出处就明说缺口，不编造引文。
- 不安装也能先读晋升、跳槽或合伙/长期承诺完整示例，或看核源翻车 / normalized_only≠exact / 错绑ID≠exact / 第二源一键核源；入口见示例索引。
- 需要时一行安装：npx skills add zhuyep/shiji-tongjian-decisions --skill shiji-tongjian-decisions；Cursor 2.5+ 也可用 /add-plugin shiji-tongjian-decisions@https://github.com/zhuyep/shiji-tongjian-decisions（尚未上官方 Marketplace）。


 和其他「历史智慧」有什么不同

| | 常见史例鸡汤 | 史鉴 |
| --- | --- | --- |
| 引文 | 常口头引用、难核对 | 可离线核验；缺口明说，不编造 |
| 输出 | 一句道理 / 榜样故事 | 路径 × 代价 × 反例 × 适用边界 |
| 类比 | 古今直接画等号 | 类比可以假；只提可核实的现实条件 |
| 不该用时 | 很少写清 | README 有「何时不该用」清单 |

30 秒自证：上方已贴正确引文与改一字的核源输出；免克隆复现见核源翻车→exact。克隆后也可跑离线核验一分钟上手里的两条命令（shiji-041 与 shiji-055），均应得到 status: exact。

 先看一次推演

 晋升会加薪，但职责、资源和工时都没有说清。我更看重家庭时间与收入稳定。接受、协商边界，还是准备离开？

| 历史对照 | 原文纠正的直觉 | 回到今天需要核实的事 |
| --- | --- | --- |
| 范蠡辞越 | 辞越时携轻宝与随从；散财是后来在齐辞相的另一节点 | 离开的理由之外，是否已有现金流、可迁移能力和退出条件？ |
| 张良退居 | 少求封赏、闭门养病之后，仍被要求出谋、行少傅事 | 减少收益或降低头衔，能否实际减少责任？ |
| 吴起迁楚 | 换到支持自己的环境，仍面对支持者去世后的政治风险 | 新机会的支持来自制度和资源，还是某一位个人？ |

这些对照提出需要验证的问题，不能由古代君臣关系推断现代上司的动机。完整示例包含原文、出处、反事实标签和三条现代路径；现实困境为虚构，未使用个人私密经历。

不安装也能先判断有没有用：读晋升、跳槽或合伙/长期承诺完整推演，挑一条你认为有用或不成立的判断，填具体反馈表。选择“只看公开示例”即可，无需提供私人经历；提交内容公开可见。读过示例与实际运行会分开记录。


 何时不该用史鉴

诚实边界（类比可以假，引文不能假）：

- 要算命、宿命或「注定会怎样」的结论时，别用。
- 需要精确的现代法律、医疗或财务建议时，别用——这不是专业咨询替代品。
- 语料里查不到可靠引文、只能编造出处时，别用；应标缺口或停，不补造引文。
- 场景与史源完全不可比、只能硬凑类比时，别用。
- 只想要一句鸡汤、不要路径与代价表时，别用。
