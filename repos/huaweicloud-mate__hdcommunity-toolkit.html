HDCommunity Toolkit

华为云社区业务的 Agent 工具包 —— 用户面 + 展示面（MCP 工具 + Skill），让 AI 编码助手以自然语言完成社区博客的写/发/评论/互动等操作。

 本工具包只包含普通用户可看/可用的能力。

支持 10 个内置 Agent：OpenCode、Codex CLI、Codex Desktop、CodeArts Agent、CodeArts Work、WorkBuddy、DeepSeek Harness (DSH)、Hermes、OpenClaw、AtomCode。

要求：Node.js ≥ 22。

 支持的 Agent

| Agent | --target | Skill 安装目录 | MCP 注册方式 |
|---|---|---|---|
| OpenCode | opencode | ~/.config/opencode/skills | 自动写入 ~/.config/opencode/opencode.json |
| Codex CLI | codex | ~/.codex/skills | 安装后打印片段，加入 Codex MCP 配置 |
| Codex Desktop | codex-desktop | ~/.codex/skills | 安装后打印片段，加入 Codex MCP 配置 |
| CodeArts Agent | codearts | ~/.codeartsdoer/skills | 安装后打印片段，加入 CodeArts MCP 配置 |
| CodeArts Work | codearts-work | ~/.codeartswork/skills | 安装后打印片段 |
| WorkBuddy | workbuddy | ~/.workbuddy/skills | 安装后打印片段 |
| DeepSeek Harness (DSH) | dsh | $DSH_HOME/skills（默认 ~/.dsh/skills） | 自动写入 $DSH_HOME/profiles//cordis.patch.yml（profile 默认 web） |
| Hermes | hermes | ~/.hermes/skills | 安装后打印片段 |
| OpenClaw | openclaw | ~/.openclaw/skills | 安装后打印片段 |
| AtomCode | atomcode | ~/.atomcode/skills | 安装后打印片段 |

另有 all（逐个内置 Agent 安装）与 generic（复制 Skill 到 ~/.generic/skills 并打印通用 MCP 片段）。未内置的 Agent 见 Other Agents。

 Quick Start

 省略 --target：自动检测

bash
npx --yes hdcommunity-toolkit install


脚本按各 Agent 自身的配置目录（~/.config/opencode、~/.codex、~/.codeartsdoer、~/.workbuddy、$DSH_HOME 等）判断当前环境：

| 检测结果 | 行为 |
|---|---|
| 恰好 1 个 Agent | 直接安装到该 Agent，输出 [auto] detected agent:  |
| 0 个 | 报错退出（exit 1），列出全部可选 --target，不会默认装到某个 Agent |
| 多个 | 报错退出（exit 1），拒绝猜测，列出已检测到的 Agent 与全部可选值 |

 codex 与 codex-desktop 共用 ~/.codex，两者会同时命中，此时按下表显式指定其一即可：--target codex 或 --target codex-desktop。

uninstall 也支持省略 --target：按"已安装本工具包 Skill 的 Agent"判断，同样只在唯一命中时执行，0 个或多个均报错并列出可选值。

update 省略 --target 时使用与 uninstall 相同的检测口径（只认已安装本工具包 Skill 的 Agent）：唯一命中即刷新该 Agent；未安装任何 Agent 时报错退出（exit 1），不会为仅存在配置目录、从未安装本工具包的 Agent 创建目录。

 逐个 Agent 安装

每个小节给出 install / doctor / status / update / uninstall 全套命令。安装后需重启会话，MCP 工具与 Skill 才会被加载。

命令语义（各 Agent 通用）：

| 命令 | 作用 |
|---|---|
| install --target  | 复制 Skill 到该 Agent 的 Skill 目录，并注册 MCP server（或打印片段） |
| doctor [--target ] | 自检：Node 版本、Skill 源、AK/SK 是否就绪、目标 Agent 的 Skill 覆盖、MCP 配置状态；不打印任何凭据 |
| status | 列出全部内置 Agent 的安装状态与目录 |
| update --target  | 按当前 CLI 版本刷新已复制 Skill（升级用 @latest）；省略 --target 时只刷新已安装的 Agent |
| uninstall --target  | 移除该 Agent 下由本工具包复制的 Skill（OpenCode 额外清理 opencode.json 中的 MCP 条目，DSH 额外清理 cordis.patch.yml 中的托管条目） |

 doctor 的 MCP 检查范围：OpenCode 与 DSH 自动校验（OpenCode 读取 opencode.json/opencode.jsonc 的 mcp.hdcommunity-toolkit；DSH 读取 cordis.patch.yml 的 id: mcp-hdcommunity 条目，文件非 YAML sequence 时显示 MCP INVALID）；缺失即 MCP MISSING/INVALID 并使 doctor 失败。其余 Agent 固定显示 MCP manual snippet，表示需按安装时打印的片段手工注册，不影响 doctor 退出码。

 doctor 省略 --target 时只汇总已安装的 Agent 并检查运行环境（Node、Skill 源、认证），未安装任何 Agent 时打印提示但退出码仍为 0（环境本身无问题）；指定 --target 时该 Agent 未安装则 doctor 退出码为 1。
