ae — agentic engineering







A fleet of AI coding agents in tmux. They message each other by name, flag when they need you, and survive reboots.

ae is a thin coordination layer over tmux for multi-agent work. Run Claude Code, Codex, OpenCode and other agent CLIs side by side, and ae makes them a fleet instead of a pile of tabs: each agent knows who it is and who else is in the workspace, agents reach each other by name, and the session shows you who is waiting for a human.

Works with Claude Code, Codex, OpenCode and other agent CLIs (supported list). Any CLI agent runs; resume is best-effort for the ones ae has not modelled.

 Why ae

- A team, not a pile of tabs. Every agent is told its name and the workspace roster. Agents send messages, ask tracked questions (request id plus an exact reply command) and review each other's work, across sessions too.
- You see who needs you. Agents declare working, waiting-user, waiting-agent, blocked or done. The tmux status bar, ae list --needs-attn, ae next and the ae app terminal UI show who is waiting for a human; Telegram reaches you away from the desk.
- Pick up where you left off. Sessions, spawned agents, conversation history and shared memo notes survive stops and reboots. ae reboot hands a context-heavy session to a fresh one from an archive.
- Mix vendors. Pair one model's work with another's review; lead on the strongest model and send bounded chores to cheaper spawned workers (delegation).
- Small and out of the way. tmux keeps panes, scrollback and attach. Session state lives in ~/.ae/, never in your repo. One checksum-verified Rust binary; no runtime or service to keep alive.

 Install

bash
curl -fsSL https://raw.githubusercontent.com/clemens33/ae/main/install | bash


The installer verifies the platform bundle (ae-core, install, SHA256SUMS) against the release manifest before extraction, publishes it read-only under ~/.ae/versions// and points ~/.local/bin/ae straight at that version's ae-core — one symlink, no wrapper. Make sure ~/.local/bin is on your PATH, then run ae init. Set AE_VERSION=2026.8.2 to pin a release. Installed ae checks for newer releases quietly; global [workspace] auto_upgrade = off disables that (upgrade).

Supported: macOS Apple Silicon (darwin-arm64) and Linux x86_64 including WSL2 (linux-x86_64-musl). Intel macOS, Linux ARM and Windows/MSYS are rejected.

 Build from source

bash
git clone https://github.com/clemens33/ae.git ~/.local/share/ae
cd ~/.local/share/ae
just install


Prerequisites: rustup and just installed; then run just rust-setup once to provision the pinned toolchain. This runs the same canonical installer and compiles a native binary for this machine.

bash
cd ~/projects/my-app
ae init
ae my-app
