README

Zinn

A kanban workflow in the terminal.



 [!IMPORTANT]
 Experimental. Commands, output, and the database schema may change between releases.
 Save a backup before upgrading: zinn backup.

 Install

sh
npm i -g @zinn-dev/cli


Requires Node.js 24.15.0 or newer. See Install for setup options, upgrading, and uninstalling.

 Quick start

Create a project, add a task, and move it through the board:

sh
zinn project create MDR --name 'Macrodata Refinement'
zinn task create MDR --title 'Refine 75% of the numbers'
zinn task list MDR
zinn task move MDR-1 'In Progress'


See the Quick start for a complete first workflow, the CLI reference for commands and input rules, and Install with coding agents for agent setup.

 Data and upgrades

By default, Zinn stores projects and tasks in ~/.zinn/data/zinn.sqlite. See Data and backups and Settings for storage and upgrade behavior.

 Development

Zinn uses Bun, pnpm, Node.js, and Git. From the repository root:

sh
bun install
bun run typecheck
bun run test
bun run test:node


Package and installed-consumer tests need pnpm, Git, and Node.js 24.15.0 or newer on PATH. The website has its own checks.

Seed and use the isolated .zinn-dev database:

sh
bun run dev:seed
bun run dev -- task list


dev:seed deletes and recreates only .zinn-dev and its SQLite sidecar files. dev always uses that isolated database; ordinary zinn commands use your configured database.

 Packages

| Package                                                           | Purpose                                 |
| ----------------------------------------------------------------- | --------------------------------------- |
| @zinn-dev/cli                         | The zinn command-line interface       |
| @zinn-dev/core                       | Shared operations and storage           |
| @zinn-dev/opencode | Zinn task inspector in the OpenCode TUI |
| @zinn-dev/tui                         | Terminal interface stub                 |

 OpenCode inspector

The @zinn-dev/opencode package adds task inspection to the OpenCode TUI. It requires OpenCode 2.2.0 and Zinn CLI 0.41.0 or newer on PATH. OpenCode loads it from the plugins array in ~/.config/opencode/cli.json:

json
{
	"plugins": [{ "package": "@zinn-dev/opencode@0.4.0" }]
}


See the OpenCode inspector guide for requirements, options, updates, and removal.
