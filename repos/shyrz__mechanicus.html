 What's This Plugin

mechanicus is an agent orchestration plugin for OpenCode, based on oh-my-opencode-slim. It includes a built-in team of specialized agents that can scout a codebase, look up fresh documentation, review architecture, handle UI work, and execute well-scoped implementation tasks under one orchestrator.

The main idea is simple: instead of forcing one model to do everything, the plugin routes each part of the job to the agent best suited for it, balancing quality, speed and cost. The Orchestrator plans the work graph, dispatches specialists as background tasks, and reconciles their results before continuing.

 ✨ Highlights

- Seven specialized agents - Omnissiah, Magos,
  Dominus, Council, Logis, Artisan, and Genetor. Each part of the job goes to
  the agent best suited for it - mix any models across any providers.
- Background orchestration - the
  Omnissiah dispatches specialists as background tasks, tracks them, and
  reconciles results before continuing - parallel work by default.
- Bundled skills - prompt-based workflows like deepwork,
  codemap, verification-planning, and reflect, assigned per agent.
- Council - run multiple models in parallel on the same
  question and synthesize a single answer with @council.
- Companion - an optional floating desktop window
  showing which agents are active, including parallel background specialists.
- Multiplexer integration - watch agents
  work live in Tmux, Zellij, Herdr, cmux, or kitty panes.
- Preset switching - swap the whole team's
models with /preset, reuse base presets, and edit local overrides while
preserving JSONC comments.
- Code intelligence tools - LSP tools, AST-aware search
  across 25 languages, and built-in MCPs for docs and GitHub code
  search.
- Fully customizable - custom agents, prompt
  overrides, per-agent skill/MCP permissions, and
  project-local customization.
