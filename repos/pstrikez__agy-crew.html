 agy-crew

Hire Google's Antigravity CLI (agy) as a staffer for Claude Code, OpenAI Codex, Pi, OpenCode and more. agy-crew is a fork of agy-staff by Keli Wen (MIT); see Relationship to agy-staff.

!design diagram

Install · Examples · Account pool · Core design · Build your own · Update and uninstall · Relationship to agy-staff

 What & Why

agy-crew lets your senior agents delegate to agy, which ships fast Gemini 3.8 Flash. Five personas: staffer (general-purpose), researcher, reviewer (code and plans/decisions), implementer, and ask — plus a model-facing jobs skill. After agy-crew install every harness invokes them as /agy-crew-; the harness plugin routes use /agy-crew: (Claude Code) and $agy-crew: (Codex).

If you use Codex you know the feeling: GPT-5.6-Sol is slow even with fast mode on. Claude Code is quicker but still not fast, and Fable quota is scarce enough that you want it orchestrating subagents, not grinding through every survey and review itself. An agy worker gives you a fast lane — second opinions in seconds, research and reviews at Flash speed, scoped implementation handled off to the side while you keep moving. And where speed isn't the point, a second model family looking at the same code buys coverage and robustness your main agent can't give itself.

!two overloaded senior agents hand the baton to one fast agy worker

 Why a fork

agy-crew keeps agy-staff's personas, background jobs and portable bash-plus-skills design, and adds:

1. a terminal command agy-crew and an install command that puts the skills into every detected harness from one shared bundle, replacing per-harness plugin caches;
2. strict mutual exclusion with upstream agy-staff (the installer refuses to run beside it);
3. an account pool for running concurrent jobs on different agy accounts with per-account, per-model-family quota awareness (see Account pool).

The -crew suffix pairs with the author's codex-staff: -staff is single-account delegation, -crew is pooled.

 How

 Invoke a persona

Type /agy-crew- in your harness (Codex: $agy-crew-) and the five personas are listed. Through the Claude Code plugin route the form is /agy-crew:staffer.

 Install

Step 1 — install the Antigravity CLI (official docs), then verify with agy --version. Node.js 20+ is also required:

bash
curl -fsSL https://antigravity.google/cli/install.sh | bash


Step 2 — install agy-crew. agy-crew and agy-staff must not be installed on the same machine (see Relationship to agy-staff); the installer refuses to run beside it.

Pick one route.

| Route | Needs | You get | Pick it when |
|---|---|---|---|
| A: npm (recommended) | Node.js 20+, npm | the agy-crew command on PATH | you want the one-command install |
| A′: git clone + node | Node.js 20+, git (no npm) | skills only; commands are node /companion/agy-companion.mjs … | npm is unavailable or unwanted |
| B: plugin managers | the harness's own CLI | skills inside the harness; no terminal command | you
