magpie-gemini-web

     

中文 | English

让 Magpie 通过你的 Google 账号使用 Google AI Studio 与 Gemini 网页版。插件在本机自动运行 AIStudio2API 与 gemini-web2api-go，提供对话、原生工具调用、Nano Banana 图片生成与 Deep Research 等能力。

 新模型支持说明：Google AI Studio (ai-studio) 默认自动跟随官方最新稳定版后端，现已直接支持 gemini-4-hydrogen（含 xhigh 思考档位）、gemini-4-carbon（需账号具备对应权益，如 Google AI Ultra）与 gemini-4-argon。Gemini Web (gemini-web) 由后端 dorokuma/gemini-web2api-go v5.0.0 原生支持 gemini-4-carbon / gemini-4-hydrogen 专用模型 ID（含 -thinking 思考变体），strict_model 开启时也能正确互认槽位升降级；登录态 gemini-4-argon 仍存在生成挂起已知问题 53，建议优先使用 ai-studio。

2. Gemini Web 后端固定使用 dorokuma/gemini-web2api-go 的官方 Release 预编译二进制（当前 v5.0.0，SHA-256 由脚本单向同步、禁止手改），移除本地补丁重编流水线。

 怎么选？

插件提供两个互相独立的 Provider，可按使用场景选择（也可同时配置）：

| 对比项 | Google AI Studio (ai-studio) | Gemini Web (gemini-web) |
| :--- | :--- | :--- |
| 适用场景 | 推荐主力与 Coding Agent 使用 | 日常对话、使用网页版额度 |
| 主要模型 | gemini-4-carbon（Ultra 等有权益账号）、gemini-4-hydrogen、gemini-4-argon、gemini-3.1-pro、Flash 系列、Deep Research | gemini-4-carbon / gemini-4-hydrogen（含 -thinking 变体）、gemini-3.8-flash、gemini-3.6-flash、gemini-3.5-flash-lite、gemini-3.1-pro、gemini-4-argon（见 53） |
| 工具调用 | 原生 Function Calling，稳定可靠 | 提示词模拟（实验性，Flash 系列常不调工具） |
| 思考档位 | 按模型目录提供 minimal / low / medium / high / xhigh（Hydrogen）中支持的档位 | low（普通）/ medium（-thinking-medium，仅 gemini-4-argon）/ high（-thinking 扩展思考） |
| 图片输入 | 默认开启，对话模型可以读图 | 默认开启，对话模型可以读图（需登录态挂 Cookie） |
| 图片生成 | Nano Banana 系列模型，供 Magpie 的图片生成使用（需要 Magpie v0.1.2075+，见下文） | 不支持 |
| 登录方式 | 自动安装官方后端，导入账号后确认连接 | 用无痕窗口登录并复制 cookie |
| 额度卡片 | 显示冷却中的模型与恢复时间 | 同步网页版 5 小时 与 每周 用量及重置时间 |
| 本地后端 | AIStudio2API（自动安装并跟随官方稳定版） | gemini-web2api-go (v5.0.0 固定 pin 二进制) |

 快速开始

在 Magpie 插件市场安装 @dorokuma/magpie-gemini-web 后，按需登录以下任一（或两个）Provider。

 从旧包迁移：0.15.0 起 npm 包名为作用域包 @dorokuma/magpie-gemini-web（此前为无作用域包 magpie-gemini-web）。已装旧包的用户请在 Magpie 插件市场卸载旧的 magpie-gemini-web 后重新安装新包；本地数据目录 ~/.local/share/magpie-gemini-web、已保存的 Google 账号、Cookie、数据库和凭据全部保留，无需重新登录或导 Cookie。迁移期卸载清理同时识别新旧两个包名，不会把新插件误判为已卸载。默认由插件下载对应后端、校验 SHA-256 并在后台自启，无需安装 Go 或其它依赖。AI Studio 默认自动跟随官方最新稳定版，也可关闭自动更新、指定自己的程序或连接独立服务。

 方式一：Google AI Studio (ai-studio)

1. 在 Magpie 中登录 Google AI Studio，选择 「添加账号并连接（推荐）」。
2. 首次使用时，插件会自动下载、校验并启动官方 AIStudio2API 最新稳定版。无需手动下载程序、填写路径、复制 API key 或设置管理员密码。
3. 按连接页提示点击 「打开账号管理页」，在后端页面添加 Google 账号，可选择 Chrome 导入、Cookie 导入或浏览器登录。
4. 返回连接页，选择刚添加的账号并点击 「连接到 Magpie」。继续使用原有的 ai-studio Provider、模型、图片生成和额度卡片；添加更多账号时重复登录即可。

已有账号提示登录过期时，在 Magpie 中选择该账号，再按连接页指引到管理页点击原账号的「重新登录」，
