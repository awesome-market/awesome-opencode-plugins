README

Oh My Mini Quant (OMMQ)

让小白用户也能通过AI助手从行情数据、财报分析到个股深度研究、估值与龙虎榜博弈的全流程投研任务,输出结构化研报。

 README.md 面向人类,AGENTS.md面向 Agent;两者冲突时以文件 AGENTS.md为准。

 项目简介

OMMQ 是一个轻量级、本地优先的 A股、期货投研工作台,不依赖MCP服务,不依赖靠积分充值的范办公工具。内置各类绘图脚本、量化策略。由 Agent 与 SubAgent 按任务类型调度,最终产出结构化、可落盘的研报、量化选股池子、量化回测结果等。并支持期货实盘交易(CTP);

 核心能力:

- 实盘:支持实盘策略，模拟策略，回测，分析账户等
- 策略:strategies/ 提供市场全景、情绪、资金流、板块轮动、期货、个股财务与技术面等可独立运行的图表脚本
- 取数:获取行情、K 线、财务、龙虎榜等原始数据
- 分析:财报速读、个股深度研究、公司质地打分、估值研判、龙虎榜掘金、业绩预告博弈
- 交互:推荐 OpenCode  开源工具及内置的免费模型,实现 0 费用对话与分析；
- 量化计算与绘图:pandas / numpy / scipy / TA-Lib 计算,matplotlib / seaborn 出图
- 产出归档:正式报告与图表统一落盘至 reports/

 策略脚本

strategies/ 下的脚本独立于技能体系,直接用拉取公开数据并出图,可单独运行或作为取数参考。图表产物按当天日期统一写入 reports/YYYYMMDD/(编号规则见 strategies/plot_paths.py:核心八图 01–08、扩展研究图 09 起,参数化脚本以代码作后缀避免覆盖)；股票财务脚本导出的 CSV 数据文件仍存 strategies/output/financials/。
