Chinese Skill

簡體中文 | 繁體中文

Chinese Skill 是供 Claude、Codex、OpenCode 與 OMP 使用的中文寫作與審查技能，適用於文章、文件、介面文字、程式註釋、commit 與 PR。

它檢查語法、邏輯、機器翻譯痕跡、口語、自造詞、冗長內容、簡繁混用及不必要的註釋。規則優先採用專案既有格式與術語；面向多個中文地區時，使用同一字形及各地讀者都能理解的標準中文。


 總圖

text
任務進來
 ├─ 定結構（包結構、資料、部署形態、前端目錄）
 │    └─▶ zakk-architecture ──介面取值──▶ web-ui
 │              └─ 必出三份文件：設計語言(web-ui) / 架構(本份) / 工作流(zakk-workflow)
 ├─ 一次改動（修復、小功能、文件、skill 改動）
 │    └─▶ zakk-maintain
 │          ├─ 1 計劃寫成檔案 ──送審──▶ 另一個頭腦
 │          ├─ 2 按批准的計劃寫說明書 ──派工──▶ dispatch --engine omp | codex | opencode
 │          ├─ 3 判 diff ──▶ zakk-review ；審者自己做消融、門禁、對拍 ；再派一個沒看過計劃的冷讀
 │          └─ 4 落倉與報告 ──▶ zakk-workflow（分支、提交、合併請求、完成報告）
 ├─ 任何中文 ──▶ chinese-skill（橫切：每份都讀，壓縮、恢復、切換任務後重讀）
 └─ 任何英文正文 ──▶ writing-skill（橫切：README、docs、註釋、提交、PR、issue）



 流程


text
入口：任何中文（文章、README、介面文案、日誌、註釋、審查、提交、合併請求、發布說明）
 │
 ├─ 何時重讀：每個工作項開始；上下文壓縮或恢復後；長工具操作後；切換任務後；
 │     寫註釋、提交、合併請求、審查之前
 ├─ 儲存庫指令優先：術語與格式依儲存庫；本份管清晰、簡潔、註釋與中文風格
 ├─ 直接寫：結果先行；具體名稱；因果用「因為…所以…」；一句一個想法；不混簡繁；不造詞；術語保留英文
 ├─ 寫與改：先定讀者、目的、locale、事實、必要術語、容許改動的幅度
 │     寫 / 改寫 / 潤飾 / 縮短 / 專業化 各按精確定義；無證據的效果宣稱 → 問一句，不補一個正式版
 ├─ 風格：standard 預設；strict / academic / technical / readme / ui 按需
 │
 └─ 交出前的最終檢查（12 條）：
      第一句給結果；每句新事實；術語對；無口語過渡與操作動詞；地區術語可懂；
      不重複標題與 diff；註釋過關；PR 與提交寫理由不寫流水帳；改稿沒變長；
      無禁用 Emoji；未把不確定說成確定；資訊完整即停



 要求

- Python 3.11 或更新版本
- Bash

 安裝

bash
git clone https://github.com/Zakk-LLM/Chinese-skill.git
cd Chinese-skill
./install.sh


預設以符號連結安裝至四個代理。Claude、Codex 與 OpenCode 會加入定期重新讀取技能的提醒；OMP 使用自身的 skill discovery，不修改 Codex 的技能目錄或 AGENTS.md。安裝程式不會覆寫不屬於本專案的檔案。

bash
./install.sh claude codex
./install.sh omp
./install.sh --copy
./install.sh --status
./install.sh --uninstall


| 代理 | 安裝位置 |
|---|---|
| Claude | ~/.claude/skills/chinese-skill |
| Codex | ${CODEX_HOME:-~/.codex}/skills/chinese-skill |
| OpenCode | ~/.config/opencode/skills/chinese-skill |
| OMP | ${OMP_CONFIG_DIR:-~/.omp/agent}/skills/chinese-skill |

符號連結安裝要求來源目錄保持不變。需要移動或刪除來源目錄時，請先解除安裝，或改用 --copy。

 使用

代理應先讀取 SKILL.md。一般使用者應直接執行工具，必要時先查閱 --help；只有維護或除錯腳本時才閱讀其原始碼。以下命令可檢查檔案、目錄或標準輸入：

bash
python3 scripts/chinese_lint.py README.md docs/
python3 scripts/chinese_lint.py --kind source src/
python3 scripts/chinese_lint.py --kind prose --style readme README.md
python3 scripts/chinese_lint.py --kind prose --style ui path/to/catalog
python3 scripts/chinese_lint.py --kind prose --format json article.md
python3 scripts/chinese_lint.py --kind prose --style readme --fix README.md
printf '%s\n' '待檢查文字' | python3 scripts/chinese_lint.py --kind prose -
python3 scripts/chinese_lint.py --kind commit-message message.txt
python3 scripts/chinese_lint.py --kind pr-body --title 'scope: summary' body.txt


| 風格 | 用途 |
|---|---|
| standard | 通用中文檢查 |
| strict | 精簡文字，禁用 Emoji 與中文程式註釋 |
| academic | 學術文章 |
| technical | 技術文章與設計說明 |
| readme | 專案入口文件 |
| ui | 控制項、狀態、錯誤及確認文字 |

--format json 輸出穩定的規則識別碼、嚴重程度、路徑、行號、訊息與樣本，供編輯器及 CI 使用。--fail-level warning 讓警告也產生失敗狀態。以標準輸入檢查資料檔時，使用 --stdin-filename 指定檔名。--fix 只修正全形英數、標點、空格及 README 標題句號，不改寫語法或用
