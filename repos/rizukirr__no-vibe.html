README

no-vibe

Turn your AI coding agent into a tutor. It teaches you, learns your level and adapts to you.

Works with Claude Code, Codex, opencode, Pi and Antigravity.

 A lesson


/no-vibe i wanna learn about matrix multiplication using assembly


1. If you are in a project, the agent reads it first, so the lesson fits your stack and never breaks what already works.
2. It finds your level with a few multiple-choice questions, and asks how you like to learn: code first, explanation first or a mix.
3. It agrees a one-sentence goal with you.
4. It researches your goal, looking at existing roadmaps and references, then works backward from your goal to what you already know and writes a roadmap of chapters for you to approve. Each chapter is required or optional, and before an optional one the agent explains it and lets you choose to do it or skip it.
5. When a chapter begins, it plans the chapter's sections. Each section says why it is needed, gives a structured explanation with visuals that show how to think about it, then at least 3 exercises with the full code shown for you to type and run.
6. Each chapter ends with a check, such as finding a bug or predicting output, and the agent re-explains what you miss.
7. For a goal in your project, the last chapters guide you to type the real feature into your own code.

Progress is saved in .no-vibe/ROADMAP.md: the roadmap, what each section taught you, and your notes on how you want to be taught, such as "write less text". /no-vibe on picks up where you left off, even in a fresh session.

 Install

Claude Code, then restart it:


/plugin marketplace add rizukirr/no-vibe
/plugin install no-vibe@no-vibe


Codex, which asks you to trust the plugin hooks on first use (see INSTALL.codex.md):

bash
codex plugin marketplace add rizukirr/no-vibe
codex plugin add no-vibe --marketplace no-vibe


Pi (see INSTALL.pi.md):

bash
pi install npm:no-vibe


Antigravity:

bash
agy plugin install https://github.com/rizukirr/no-vibe


opencode v2, with bash on PATH: add the plugin to opencode.json, then run opencode reload (see .opencode/INSTALL.md):

json
{
  "plugin": ["no-vibe@git+https://github.com/rizukirr/no-vibe.git"]
}


 Commands

Codex uses $ instead of /.


| Command | Effect |
|---|---|
| /no-vibe [on\|off\|] | Learning mode. Use ONLY when .no-vibe/active exists at the project root or the user invoked /no-vibe. The agent teaches in chat and never writes project files. Every reply starts with the header [no-vibe] Step:  · Chapter:  · Section:  · Exercise: . |
| /no-vibe-btw  | One-shot escape hatch to temporarily disable no-vibe write guard for a single scoped task, then restore the marker. |


 The write guard

While no-vibe is on, a hook refuses file writes and shell writes outside .no-vibe/ (shell commands may also write to /tmp).
