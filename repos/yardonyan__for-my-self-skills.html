中文 · English



 Yardon Skills

 18 个在真实项目里用过、整理出来的 Agent Skills










这些 Skill 都按 Agent Skills 开放标准组织。Claude Code、Codex、Qoder、Cursor、CodeBuddy 等支持该标准的工具可以直接加载。每个目录都有 SKILL.md，先读它，再按需读 references/。

不是提示词合集，也不是把所有能力塞进一个巨型 prompt。每个 Skill 只解决一类问题，触发条件、产出形态和边界都写在 SKILL.md 里。装上之后，Agent 在该用的时候会自己读。

按「用在哪一步」分成四类，一个 Skill 只归一类。先看下表找方向，再展开对应分类看细节。

 分类

| 分类 | 管什么 | Skill 数 |
|---|---|---|
| 网页与前端 | 产出界面，或修界面上看得见的问题。写页面的规范、视觉与移动端适配，以及 Markdown、SSE 这类渲染层的排错。 | 4 |
| 文档与交付 | 把内容变成别人能直接打开的文件：转换要保真，演示要能看懂，发布要落到位。 | 4 |
| 工程流程与质量 | 管怎么做，也管做得对不对。从需求到设计的流程、代码审查标准、任务并行编排、文档合并裁决、造 Skill 的方法、主动型 Agent 的系统设计，以及经验怎么沉淀下来。 | 7 |
| 写作与表达 | 把想法写成别人能准确读懂、模型能准确执行的东西。 | 3 |
