Agent Lifecycle Kit



!Python

Agent Lifecycle Kit (ALK) coordinates coding-agent work through a verifiable finish. It keeps the requested outcome, reviewed plan, execution boundaries, evidence and acceptance decisions connected while the external agent changes the project.

ALK secures imports and documents the external AI SDLC CLI contract and eight bounded consumer cases. Wheel/sdist include both guides and case JSON; the plugin ships the paired CLI contract. Native authority and release gates remain required.

The provider-neutral workflow works with Codex, Claude Code, Qwen Code, Goose, OpenInterpreter, Pi, Grok Build, or another CLI. Provider commands, model choice and secret handling stay in adapters or host-local profiles.

Release 2.28 adds bounded lifecycle and accounting baselines. Repository tools measure real read-only operations and separate fixture preparation from operation and subprocess time. The Windows fixture comparison observed a 13.08% median reduction in one six-sample experiment; it is not a universal speed promise. All security and platform checks remain required.

 Quick start
Start with install ALK and make the first run. Release 2.23 adds compact S0/S1 authoring with explicit checklist completion and unchanged approval gates. Release 2.22 adds conservative plan-review reuse with independent current applicability and no automatic full reruns. Release 2.21 adds command accounting, bounded preparation and response recovery. Release 2.20 adds target-bound initialization, bounded local continuation and batched Git snapshots. Release 2.19 adds safe artifact authoring and planning preflight, bounded review handoff and thin skills with complete references. Release 2.18 bounds process/Git diagnostics, hardens signing and distinguishes OpenCode 1.x/2.x compatibility (adapter notes); 2.17 strengthens workflow validation and recovery. Release 2.16 introduced cumulative accounting within verified host capabilities; see retention maintenance.

It includes macOS, Linux and Windows instructions, Python 3.11-3.15, PyPI installation with python -m pip install agent-lifecycle-kit==2.48.0, and common agent-lifecycle version errors. See 2.15 migration notes and authority boundaries.

For a quick start, run:

bash
git clone https://github.com/avksp/agent-lifecycle-kit.git
cd agent-lifecycle-kit
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
agent-lifecycle version
agent-lifecycle diagnose --no-install-plans


Choose  from the adapter support matrix and pass a task from a file:

bash
agent-lifecycle start --adapter  --file task.md


- Then choose a suitable scenario in how ALK works for different tasks.
- The boundaries of planning-only launch and frozen-task launch through a verified profile are documented in the reference. Shipped planning profiles remain candidates with safe failure until the corresponding profile is verified.
