README

Spawn the team. Steer every agent.


  Open-source workspace that runs AI coding CLIs side by side on your machine.
  25 CLIs, each in its own tmux window. One of them can drive the rest over MCP.



  
  
  
  
  



  
  
  
  
  
  



  
    
    
  


ReevesAgents is a free, open-source workspace for AI coding agents. It runs Claude Code, Codex, Kimi, OpenCode, Gemini CLI and 20 other coding CLIs side by side, each in its own tmux window, and gives you a terminal UI, a browser UI and a scriptable CLI over the same runs. Attach its MCP server to one CLI and that agent can spawn, read, steer and stop the others. Every CLI keeps its own login, and ReevesAgents keeps its state in a few JSON files under ~/.reeves.

---

 Why ReevesAgents

You already use these CLIs, and you are already signed in to them. ReevesAgents runs them as a team on your machine and leaves every login where it was.

|  |  |
|---|---|
|  25 CLIs, one workspace | Claude Code, Codex, Kimi, OpenCode, Hermes, Gemini CLI and 19 more start from one command. Each runs as the real CLI in its own tmux window, so agents keep running after you close the UI. |
|  One agent drives the rest | reevesagents attach cc gives Claude Code the MCP tools to spawn, read, steer and stop other agents. Codex, Kimi Code, Qwen Code, Hermes and OpenCode can host it too, and it stays off until you attach it (details). |
|  Your logins stay put | Each CLI signs in the way it always does. ReevesAgents stores no API keys, adds no proxy, and redacts token-like text in tasks, notes and approvals before it writes state. |
|  Four ways in | A terminal UI, a Web UI with a live pane per agent, a CLI with --json output for scripts, and the MCP. All four read and write the same runs. |
|  Plain local state | A few JSON files under ~/.reeves, with no database and no Docker. The Web UI answers on 127.0.0.1 only and rejects foreign Host and Origin headers (guards). |
|  macOS, Linux, WSL, Windows | tmux 3.0 or newer on macOS, Linux and WSL. Native Windows 10 1809 or later runs on the built-in winmux multiplexer over ConPTY, without WSL (2.1.0). |
