超级麦吉 Magicrew for magpie

  ⚠️ 已停止维护 —— 最后一个版本 1.0.0（2026-11-04）

 仓库保持公开、代码留档，但这个版本之后不再更新、不再修 bug、不再跟上游变更。
 下面这些坑不会有人来补。

  封号风险警告

 请只用一次性小号 / 副号。绝对不要把主力账号挂在这个插件上。

 2026-11-04 实测：本机一个主力账号（已脱敏）被上游禁用——

 text
 GET /api/v1/auth/status        → {"code":3109,"message":"该账号已被禁用，无法登录。"}
 GET /api/v1/quota/points/total → {"code":2155,"message":"用户不存在"}
 GET /api/v1/flows/models       → {"code":2155,"message":"用户不存在"}
 

 同一 owner 下的其他 3 个登录标识（均已脱敏）
 在 logins.json 里一律报 用户不存在。网页端登录同样进不去（见下一条）。

 封号原因无法证实 —— 上游没有给理由，也没有任何证据能断定是插件引起的，所以这里不下结论。
 但风险是真实的：这个插件会替你自动签到、自动补新人任务、自动拉模型与积分、每两小时续一次 key，
 这些在服务商眼里都属于「非官方客户端」行为。用不用、用什么号，自己权衡。

  截至 2026-11-04 的上游阻断（都没修完）

 - 国内站 i-magic-service.letsmagic.cn 被火山 WAF 按 Host 整域名拉黑（403 空 body +
   X-TT-System-Error: 3）。同一 IP、同一 SNI，只换成 openapi.letsmagic.cn 就 200，
   0.3.78 起插件已改走那个域名 —— 但 官网自己的登录页还在用被拉黑的那个，
   所以网页登录会卡在「点下一步没反应」（/api/v1/auth/status 回 403，前端静默吞掉）。
 - 国际站 magic-service.magicrew.ai 被阿里云 ESA 回 405（响应头 Punish-Loc: keepper），
   换 UA / Origin / IPv4 / 请求方法都无效，也没有别名域名可换（openapi.magicrew.ai 不解析）。
   国际站这半边没修好，最后一个版本带着这个已知缺陷发布。

一个包，两个供应商：国内的 GLM / DeepSeek / Qwen / Kimi，国际再加 Claude / GPT / Gemini —— 原样走它的 OpenAI 兼容网关。

超级麦吉（letsmagic.cn，官网英文名 Super Magic）和 MagiCrew（magicrew.ai）是同一产品的两套云。这个插件把它们各接成一个独立供应商 —— 在 magpie 的供应商列表、用量概览、模型目录里各占一行，不聚合、不互相覆盖登录态。

 显示名按「中文 + English」，英文照抄官网：插件卡片是 超级麦吉 Magicrew
 （写在 package.json 的 magpie.name，name 只做 ASCII 依赖键 —— 见下），
 两个供应商分别是 超级麦吉 Super Magic 与 麦吉 MagiCrew（Super Magic 是两个词；
 MagiCrew 官网没有中文名，「麦吉」取自官网正文里对自家产品的简称）。

 ⚠ 装过 0.3.69 的话要重装一次：那一版的包名带中文，magpie plugin update 会报
 unrecognised dependency format。magpie plugin rm github:MYCF711/magpie-magicrew-auth
 再 plugin add 同一个地址即可（登录态不丢）。

 功能

- 两个供应商分得开 —— 国内、国际各一行，图标、名字、模型、积分、登录态全部独立
- 登录全程不开浏览器 —— 国际站有邮箱验证码和手机号验证码两条纯 HTTP 路；国内站有手机号验证码。另外两条（浏览器登录 / 手填登录态）谁都能用
- 已有的账号加进来，只填两次就完事 —— 填邮箱（或手机号）→ 填验证码。那张「拖动滑块使图片角度为正」的旋转图根本不会出现：服务端对已注册的账号直接放行，插件用的就是这条通道
- 本机浏览器登过就直接认 —— 你平时那个 Edge / Chrome / Brave 里登过 magicrew，点「浏览器登录」时插件读它的 localStorage 接上：不开窗口、不用重登
- 模型跟着账号走 —— 每次登录后按 /api/v1/flows/models 实时拉，账户当前能选什么就展示什么，生图和 embedding 不会混进来
- 积分算得准 —— 余额读的是 /api/v1/quota/points/total；空号就显示空，不会被优先派活
- 积分耗尽自动换号 —— 上游用 HTTP 400 报「可用积分已不足」时，插件把它改写为语义正确的 402 Payment Required，magpie 会 rest 这个账号并继续问同 provider 的下一个账号 / 路由组的下一个成员
- 登录一次管 30 天 —— 网页 JWT 顶 30 天，mgw_ api_key 每 2 小时自续，refresh_token 每次续期时自滚
- 新手奖励 8 项全自动 —— 国内站 8 项 500 积分全部拿得到；第 8 项（完成第一次 AI 工作）由插件替你发一条消息，花掉约 2 积分
