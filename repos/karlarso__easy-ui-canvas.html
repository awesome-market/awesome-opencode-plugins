Which prompt do you need? Use the first if Easy UI Canvas is not on this machine yet. Use the second if it is already running — the list page is up — and you want an assistant to use that instance. The assistant reads the Agent guide on the list (/agent.md). It does not install a usage skill.

 🎨 What it is

A small local web canvas for exploring UI designs: put several HTML screens (frames) side by side on a zoomable, pannable board, comment on individual elements, click through flows on a phone, and let an AI coding agent read and answer the comments in the next session. It runs on your machine and needs only the Python 3 standard library. A running list serves an Agent guide at /agent.md. Everyday use is to fetch that page. Deploy stays DEPLOY.md.

 ✨ Why use it

- 🔌 Works with any AI coding tool. Any assistant that can read files and run commands (Claude Code, Cursor, Codex and others) can use it, so you can switch tools or models without switching canvas.
