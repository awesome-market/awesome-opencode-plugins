agent-wechat-bridge

Drive your coding agents from WeChat. agent-wechat-bridge connects OpenCode (a V2 server plugin) and Codex (hooks) to a WeChat ClawBot (the iLink bot API). Replies are pushed to your phone, you approve permission requests and answer the agent's questions by replying, and you can send new messages, images and files to any conversation. Node standard library only, no dependencies.

The full documentation is in Chinese: 中文说明.

 Features

- Push: the final reply of each turn, live progress (merged, at most one message per 15 s, one per 60 s once half the send quota is used), and errors arrive as [3] OpenCode · project / title followed by the text. Images mentioned in a reply are sent too.
- Approve: permission requests arrive with the action to run. Reply 3 y or 3 n. For Codex desktop you can answer on the PC or in WeChat, whichever comes first.
- Answer questions: the agent's question tool shows the options in WeChat. Answer with an option number, an option's text or free text, all at once or one by one.
- Control: 3 your message continues conversation 3 (OpenCode or Codex, shared numbering), 3 shows its last reply, and 3 历史 reads back recent messages. Also /model (模型, 模型 46, 3 模型 46), 3 /stop (stop conversation 3's running reply), /compact, undo, and starting a new conversation in a folder you pick.
- Thinking effort: 思考 lists the levels the conversation's model offers and marks the current one. 思考 高, 思考 2 or /effort high switch, and 3 思考 低 sets conversation 3. OpenCode changes the conversation's model variant, so the desktop app follows; Codex uses the level from the next turn sent from WeChat. A model without levels says so. /model keeps the current level when the new model has it too.
- Pause: /stop (no number) pauses the whole bridge: no pushes from the plugin, the daemon or the Codex hooks, no WeChat commands, Codex permission requests are left to the PC, and the Codex background program (the bridge's own codex app-server) is closed. /start resumes and opens it again. See Pause and resume.
- Fast after sleep: while the bridge runs, the process that receives your messages keeps the Codex background program up, so the first message to a Codex conversation no longer waits for it to start (3 to 9 s here). 帮助, 列表 and 额度 answer at once even while a Codex message is still starting, and after the PC wakes from sleep the bridge reconnects immediately. See Codex background program.
- Send images and files from WeChat into a conversation. Drop a wrong one before the text goes out: 不要 2 removes item 2, 发错了 removes all.
- Files on request: after each turn the bot lists the files the agent mentioned or changed (images still send themselves; likely secrets such as .env or .pem are never listed). Nothing is sent until you pick: 3 文件 1 3 sends the 1st and 3rd of conversation 3, 3 文件 全部 sends all, 文件 path sends
