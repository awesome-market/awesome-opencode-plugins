FlameWM

A window manager and desktop shell for Linux, written in Rust, with its UI in HTML and CSS compiled to native code.

Extremely efficient. Two sessions: X11 and Wayland.


!Rust
!X11
!Wayland

---

 Why FlameWM

- Native and small. The shell is HTML and CSS, compiled at build time. There is no embedded browser. Idle figures are in Performance.
- One desktop, one owner per job. The window manager, shell, settings, lock screen and apps are separate crates. The layering rules are in docs/ARCHITECTURE.md.
- Honest status. Open work is tracked in docs/TODO.md. Known issues are listed below, not hidden.
