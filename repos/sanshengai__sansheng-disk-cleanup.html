叁笙清理 · sansheng-disk-cleanup

中文 | English


  
  


最懂「AI 垃圾」的磁盘清理 Skill

Codex、Claude Code 用了几个月，磁盘满了却不知道满在哪？通用清理软件只认浏览器缓存和日志，AI 对话记录、批量生成的图、项目中间稿、模型缓存，它们既不认识也不敢动。叁笙清理专清这些。



作者本机实测：一次腾出 23.9 GB，其中 21.3 GB 是 AI 留下的——对话记录 10.1 GB、项目中间稿 7.7 GB、生成的图 2.0 GB。

觉得有用，请先到 GitHub 仓库 点个 Star。安装只要把这句话发给你的 AI（Claude Code、Codex 等支持 SKILL.md 的 Agent）：

text
请从 https://github.com/sanshengai/sansheng-disk-cleanup 安装这个 Skill，然后帮我看看磁盘空间都去哪了。


当前正式版本见 GitHub Releases。仅支持 macOS；Windows 尚未支持。

 三个亮点

 有脑：认得 AI 垃圾，查清再删

它认得各家 AI 工具把对话、图片、中间稿存在哪；删之前先查清每一项是谁留下的、为哪个任务、做完没有、还有谁在用，查不清就不动。认不出的大目录，它会去看里面是什么，查清楚记下来，下次直接认得。密码、未提交的代码、正在用的对话由脚本强制保护，AI 也放行不了。



作者本机：认出 6 个 AI 工具和开发环境，合计 113.3 GB，单 Codex 就占 73.7 GB。

 能成长：越用越懂你

第一次用一页选择题认识你：哪些工具常用、项目做完没有、成品放在哪、删掉的东西放不放废纸篓。以后沿用你已确认的保留边界；扫描发现的新习惯先给你审阅，不会自动改全局记忆或扩大删除权限。会一直涨的东西（AI 工具一直存对话、脚本重复存图），经你同意从源头改掉，下次清理告诉你是不是真的停了。

 能互动：一页看板，你来拍板

不用看命令行：一页看板看清空间都去哪了，勾一勾、点一下就决定；小事在对话里回一句“好”就行。暂时没有能执行的清理项，也会交付看板；证据还不够的旧任务，可以选择“想清理，继续查 / 保留 / 暂不确定”，让 Agent 继续核查。这些回答本身不授权删除。删之前先预演、再试删一条，并讲清本轮是直接永久删除、还是先放废纸篓。完成后给一页成果页：已释放、待彻底删除分开显示。先暂存后决定腾空间时，可授权 Agent 只永久删除本轮已核实的普通单文件，不动废纸篓的其他内容。

 还有这些

- 几分钟出结果的分档体检：scripts/triage.py 只读并行测量，分成“可直接清的缓存 / 可移除的工作树 / 要你判断的 / 在用或受保护的”四档，每项附先检查、再删除两条命令；正在生产的成品目录、被台账登记的路径默认保护，只认盘外备份为可恢复。
- 你说“都删”时，也逐项复核：你在对话里整批授权后，Agent 把清单交给 scripts/quick_act.py 执行，不再临时写脚本。删前逐项检查：别的 Agent 是不是还在用（近期提交、其他会话的对话记录、目录里的脚本、代码引用），有没有盘外备份（可接你自己的网盘备份，先补传、再回读核对）；没有备份的过程件只改名隔离 7 天。每一项都写进清理日志，附恢复办法。
- 空间异常才提醒：scripts/disk_watch.py 一秒读完余量，和一周前比，余量过低或涨得太快才弹通知；不装定时任务，想每天看就挂进你已有的定时任务。
- 重复副本只占一份空间：同一文件在成品库、交付、分发暂存里各存一份时，全量核对后改成 APFS 克隆，每个路径照常可用，删副本才会破坏的交付目录也不用动。
- 大目录拆到任务阶段：追查 Agent 的外部工作区、副本和批量小文件，区分原始输入、当前工程、正式成果与已结束的过程件；网站装配、旧安装包、登记暂存和渲染现场分别核验。
- 任务结束主动收尾：让产生文件的 Agent 按归属记录输入、过程件和保留成果，在阶段完成时清理已有授权覆盖的无用过程件，避免一直累积。
- 近期文件可以精确授权：默认保护最近 24 小时有改动的文件；你明确允许本轮清理时，授权绑定精确清单并在删除时复核，当前活动现场和唯一输入仍保留。

- 解释空间为什么快速减少：每次扫描留下精简记录点，下次自动比较同范围的目录；正式清理后另记磁盘实测余量。能追到增长来自哪个任务，区分新增占用与垃圾，并把暂时无法归因的差额说明白。只保存元信息，不重复扫描硬盘。
- 你决定它能看什么：四档读取范围——基础（项目说明、脚本、日志）、扩展（聊天收到的文件、邮件附件、照片截图，只看名字和大小）、深度（聊天正文、图片内容）、永不读（密码、钥匙串、浏览器登录数据、密钥，脚本强制）。读到的内容会发给你所用的 AI 服务商，成果页列出这次读了哪些文件。
- 删和留之外的第三条路：先放废纸篓能反悔；做完的项目可以搬到外接硬盘，逐个文件校验一致才处理原件；iCloud 和网盘只给“只留云端”的官方做法，不动你的文件。
- 安全不变：设置和记忆只改变“问不问、默认勾哪些”，不改变能不能删；不用 sudo、不装常驻程序，只在本机运行。
- 能分享：成果页可以存一张分享图，发朋友圈或群里。

 第一次怎么用

1. 快速看一遍：先扫一遍电脑，约 1 分钟，认出装了哪些工具、有哪些项目。
2. 一页选择题：按你的电脑出题（没装 Docker 就不问 Docker）。AI 重度用户大约 5 分钟，也可以一键全部按推荐；想改随时对它说“改设置”。
3. 再深入看：按你的回答去读该读的文件、查完成的证据；常用工具和进行中的项目也深入拆查，只退役已经完成、没有当前消费者的具体子任务。
4. 清理看板：把能清的、要你拿主意的列出来，每项写清依据和后果。
5. 成果页：腾出多少、这次读了哪些文件、这次我记住了什么、从源头改好了什么。

以后每次：扫描 → 清理看板（或在对话里回一句“好”）→ 成果页。

 手动安装

也可以自己克隆到 Agent 的 Skill 目录，例如 Claude Code：

sh
git clone https://github.com/sanshengai/sansheng-disk-cleanup ~/.claude/skills/sansheng-disk-cleanup


需要 Python 3.9 及以上，只用标准库；装有 rg 时引用检查更快、更全。GitHub 打不开时，可以到官网下载备用安装包。

 为什么需要它

常规清理工具找的是浏览器缓存、日志、废纸篓，经常用 AI 工具的电脑上，大头却在别处：

- Agent 会话：比如用 codex exec 批量出图，同一张图会存三份。每个会话只有几 MB，按大小排序永远排不到前面，累积起来却很可观。
- 流水线中间稿：视频分镜、配图小样、试画废稿、构建输出、多棵工作树里的临时产物。
- 模型与工具链：模型权重、模拟器
