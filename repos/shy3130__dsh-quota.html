dsh-quota

DeepSeek Harness 输入框状态栏 · 多厂商额度与消耗监控插件

智谱 GLM · OpenCode Go · Kimi For Coding · 小米 Token 套餐 · DeepSeek 官方










跟随当前模型自动切换 · 点开即看额度、倒计时、Token 用量与费用 · 数据本地聚合，凭据不外发

bash
dsh plugin --profile desktop add github:shy3130/dsh-quota

 目录

特性 · 效果图 · 安装 · 配置 · 使用与工作原理 · Token 用量统计 · DeepSeek 官方监控 · 隐私与安全 · 开发 · 项目结构 · 许可证

 特性

- 自动跟随当前模型 —— 宿主读取 DSH 的默认模型选择，切换后约 1 秒内切到对应厂商徽标；未覆盖的厂商徽标自动隐藏、不占位
- 五家额度来源
  - 智谱 GLM：5 小时窗口 · 本周 · 本月工具额度（含分项）
  - OpenCode Go：5 小时滚动窗 · 本周 · 本月
  - Kimi For Coding：5 小时窗口 · 本周汇总
  - 小米 Token 套餐：套餐额度 · 补偿额度 · 本月总量
  - DeepSeek 官方：今日本机总 Token 用量（K / M / B 换算）+ 今日消耗 + 账户余额（充值 / 赠送）；7 天 / 30 天在弹层里切换
- 明细面板 —— 剩余 / 已用 / 重置倒计时（6d 21h 紧凑格式）、工具额度分项、柱状 / 环状指示器可切换并记忆
- Token 用量统计 —— 弹层里可切换今日 / 7 天 / 30 天：总量、输入 / 输出、缓存命中率、请求数与每日柱状图，全部本地计算；总量按 K / M / B 换算，徽标最左侧固定展示今日全厂商总用量
- DeepSeek 费用估算 —— 按官方价目表（区分高峰 / 空闲时段）由本地 token 记录估算金额，不需要官方用量接口
- 手机端适配 —— 窄屏（≤520px）下徽标自动紧凑（隐藏分隔符、缩短进度条；DeepSeek 徽标只保留 Token 用量与余额），弹层横向铺满并限制高度，触屏点外部关闭
- 纯插件、零侵入 —— 不修改任何官方源码；标准 DSH bundle，一条命令安装；所有路由带 DSH 登录门

 安装

 环境要求

| 依赖 | 要求 |
|---|---|
| DeepSeek Harness | 0.2.2-rc.1（RC 预览版，实测版本；≥ 0.2 理论兼容） |
| Node.js | 无需单独安装（使用 DSH 宿主自带运行时） |
| 凭据 | 对应厂商的 API Key / Cookie，见配置 |

 客户端版本：本插件在 DeepSeek Harness 0.2.2-rc.1（桌面端 RC 版）开发与实测。DSH 处于 RC/预览阶段、接口迭代较快，升级客户端后如遇徽标不显示或面板异常，请到 Issues 附上 dsh --version 反馈。

 从 npm 安装（推荐）

bash
 安装最新版
dsh plugin --profile desktop add @wshylabs/dsh-quota

 钉住某个版本
dsh plugin --profile desktop add @wshylabs/dsh-quota@1.5.0

 更新已安装的版本
dsh plugin --profile desktop update @wshylabs/dsh-quota


 从 GitHub 安装

bash
 安装（跟踪 main 最新提交）
dsh plugin --profile desktop add github:shy3130/dsh-quota

 钉住某个版本（git tag 即可，不需要 GitHub Release）
dsh plugin --profile desktop add github:shy3130/dsh-quotav1.3.1

 更新已安装的版本
dsh plugin --profile desktop update @wshylabs/dsh-quota


- 安装 / 更新后需要完全退出并重开 DSH：宿主插件在启动时加载，仅刷新页面不够
- 各版本改动说明见 Releases（只打 tag + 说明，不打源码包）
- pnpm-lock.yaml 会把 GitHub 依赖钉到具体提交（codeload.github.com/.../tar.gz/），「更新」就是重新解析目标 ref 的最新提交——与 GitHub Release 无关，push 到 main 后 update 即可拉到

 从源码安装（开发）

bash
git clone https://github.com/shy3130/dsh-quota.git ~/Project/dsh-quota
dsh plugin --profile desktop add link:/Users//Project/dsh-quota


或写进用户补丁层 ~/.dsh/cordis.patch.yml：

yaml
- insert:
    - id: dsh-quota
      name: '/Users//Project/dsh-quota/index.js'


 name 要指向 index.js 而不是包目录：Node 的 ESM 不支持目录导入；客户端模块系统会从该文件向上找到 package.json，读取 dsh.client 后再加载 client.js。

 卸载

bash
dsh plugin --profile desktop remove @wshylabs/dsh-quota
