Pulse

Glanceable market data, wherever you work.

Website · Mac App Store · Feedback

Pulse keeps stock, index and crypto prices where you already are: the macOS
menu bar, your AI coding tools, your terminal and your desktop bar.
Pulse for Mac is the full app, closed source. This repository holds the
free, MIT-licensed editions for other tools, and the documentation for the MCP
server built into Pulse for Mac.

 Editions

| Edition | Runs in | What it does | Status | Get started |
| --- | --- | --- | --- | --- |
| Pulse for Mac | macOS menu bar | Named watchlists, intraday and candlestick charts, positions and P&L, MCP server | Closed source, paid, 30-day free trial | Website · App Store |
| Pulse MCP | Pulse for Mac | Quotes, symbol search, watchlists and positions for AI agents | Built into Pulse for Mac (docs only) | Guide |
| Pulse for Claude Code | Claude Code, Claude Desktop's Code tab | Prices above the prompt, /pulse panel to manage tickers | Open source, MIT | Guide |
| Pulse for opencode | opencode | Sidebar watchlist with today's line and a detail view, quote band | Open source, MIT, on npm | Guide |
| Pulse for Herdr | Herdr | Watchlist docked beside your agents, with a detail view | Open source, MIT | Guide |
| Pulse for Rex | Rex | Watchlist in a pane beside your agents, with the selected ticker's chart and a detail layer | Open source, MIT | Guide |
| Pulse for Metrix.Bar | Metrix.Bar menu bar | Ticker in the menu bar, watchlist with search and a detail view | Open source, MIT | Guide |
| Pulse for Omarchy | Omarchy 4 bar (Linux) | Prices in the bar, named watchlists, search, charts | Open source, MIT | Guide |
| Pulse for Raycast | Raycast | Search any symbol by ticker or name, with its price and today's chart | Open source, MIT, in Raycast Store review | Guide |

The open-source editions need no account or API key. Stocks and indices come
from Yahoo Finance and crypto pairs from Binance's public Spot data; each
guide describes its edition's data sources, storage and privacy.
Positions, P&L and the MCP server are only in Pulse for Mac.

 Pulse for Mac

Market data in your macOS menu bar, with named watchlists, charts, and position
tracking. Visit pulseticker.app for features,
downloads, and current purchase terms, or get Pulse from the
Mac App Store.

Pulse for Mac is a paid app with a 30-day full-feature trial, followed by
a one-time purchase. See pricing and downloads.

Pulse for Mac includes Pulse MCP, a local MCP server that gives Claude Code,
Claude Desktop, Cursor, Codex, VS Code and other MCP clients quotes, symbol
search, watchlists and positions over 127.0.0.1. See the
Pulse MCP guide for its 15 tools and client configs.
