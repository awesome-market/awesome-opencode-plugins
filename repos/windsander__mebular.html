Use with DSH
Install the plugin from npm into DSH's web profile:
dsh plugin --profile web add @mebular/dsh-plugin@0.3.4
The App and the DSH Plugin are two equal entries to one local Mebular runtime: the plugin defaults to attach and connects to an existing App/CLI/service without starting or downloading anything. If no runtime exists, the panel explicitly offers a pinned shared-runtime install. The sidebar panel embeds the same Console through ?embed=dsh (loopback only), and the official MCP client reaches the same graph. The plugin is an independent adapter with its code isolated in packages/dsh-plugin; it is published by its own npm job, while its version follows the unified release train. For plugin development, install from packages/dsh-plugin instead.
Listed under memory on awesome-dsh-plugin and dshmarketplace.dev; every other directory is tracked in community listings.
