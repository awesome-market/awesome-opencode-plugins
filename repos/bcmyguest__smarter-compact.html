Smarter Compact





Context management (smart compaction) for coding agents. Long sessions keep small, cached prompts. Every message goes into a local SQLite session store. Once the prompt reaches your token limit, older turns leave it, and the next kept turn carries a pointer to them.





The agent searches the store with smart_compact_search, smart_compact_sql, and smart_compact_get when it needs a detail back. The cut stays put on later requests, so the prompt cache keeps hitting.

Learn more: How it works · Benchmarks · Context proxy & port · Context store

Benchmarks: On ContextBench (paper, dataset) with Haiku 5.5, smart compaction cost 85% less than keeping everything, averaged over four task sizes (v0.9.0, 2026-11-09). Tables and charts · Methods and caveats.





Trimmed context is marked with a [smarter-compact: …] pointer.

You need Node 24 or newer (for node:sqlite). Agents that trim through the proxy also need LiteLLM 1.109.0rc1 (pinned) on PATH as litellm. smarter-compact enable installs it with uv tool install when it is missing or another version. Without uv, it stops and changes no agent config. The plugin has no API key of its own. Your agent keeps its own login.

 How agents integrate

Smart compaction needs something that sees and rewrites the model request before it is sent: a proxy or an in-process hook.

| Tier | Agents | What you get |
| --- | --- | --- |
| Full trim (proxy) | Claude Code, Codex, OpenCode 1 | smarter-compact enable points the CLI at the loopback LiteLLM proxy; every turn is stored and older turns drop off the wire at the token threshold. |
| Full trim (in-process) | OpenCode 2, Pi | JS port of the trim core in the agent's context hook; includes prose strip, observation masking and the progress note (OpenCode plugin, Pi extension in this package). No proxy URL. |

Cursor and Copilot CLI get hooks and MCP search tools only, with no automatic trim. See Optional: Cursor and Copilot.

 Install

Install from npm with npm install -g smarter-compact, then register plugins with smarter-compact plugins add . It finds the installed package itself, so you need neither npm root -g nor a git clone. smarter-compact enable -g detects Claude Code, Codex, and OpenCode (by config dir, or opencode on PATH), points each at the proxy, and starts the proxy. It prints each step to stderr; -q (or SMARTER_COMPACT_QUIET=1) prints only errors and warnings. Clone the repo only to develop the trimmer or to pin a checkout path.

 Claude Code

sh
npm install -g smarter-compact
smarter-compact plugins add claude
smarter-compact enable claude


Start a new claude session after enable. The marketplace install registers the search tools and the compact command. enable points ANTHROPIC_BASE_URL at http://127.0.0.1:4101, starts the LiteLLM proxy in the background when needed, and stores a key in ~/.config/smarter-compact/proxy.env (mode 600). Session hooks also ensure the proxy is up. enable saves any previous base URL in ~/.config/smarter-c
