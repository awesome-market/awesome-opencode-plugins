opencode-status-phrases

opencode opencode-plugin plugin status-phrases russian humor desktop tui ai-coding claude-code-alternative

Плагин для OpenCode: во время работы агента показывает над полем ввода смешные статус-фразы на русском — новые меняются при смене шага/инструмента. Работает в Desktop (пилюля над композером) и в TUI (строка статуса).

 Установка


opencode plugin add christianromeoscursor365/opencode-status-phrases


Вручную: закройте Desktop (opencode service stop), скопируйте содержимое репозитория в ~/.config/opencode/plugins/status-phrases/, откройте OpenCode — плагин подхватится автоматически, конфиг править не нужно. Для TUI работает из той же папки.
