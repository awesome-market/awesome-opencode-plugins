AIKS · AI Knowledge Sync


  



  
  
  
  


让 AI 对话不再是一次性消耗。 AIKS 是面向开发者的本地优先 AI 知识库：汇集 Claude Code、Codex CLI、Cursor、OpenCode 等编程助手的本地历史会话，以及 ChatGPT、Claude、DeepSeek 等平台的公开分享链接，将有价值的 AI 协作经验整理为可搜索、可追溯、可复用的知识。

16 类本地 AI 编程 / Agent 来源 + 8 类网页公开分享来源 = 24 类来源。 本地 Provider 只读、按需启用；AI 提炼和 Embedding 可选，默认不开启。支持全文搜索、可选语义检索、项目关联及 SiYuan 文档同步。

⬇️ 下载最新版本 · 快速开始 · English · 数据源兼容矩阵 · 问题反馈

 AIKS 能帮你做什么？

| 汇集 AI 会话 | 提炼知识 | 搜索和复用 |
| --- | --- | --- |
| 在一个入口浏览多种 AI 助手的历史工作记录，无需手动复制粘贴 | 对话清洗、无损分块、AI 提炼，形成知识条目并关联项目、标签及来源 | 全文检索、可选语义搜索及「问 AIKS」，也可以按需同步到 SiYuan |

不是另一个聊天机器人，也不只是聊天记录查看器。 AIKS 的目标是让你下次遇到相似问题时，能找到之前与 AI 协作形成的解决过程和结论。

 快速开始

1. 从 Releases 下载适合 Windows、macOS 或 Linux 的安装包（以对应 Release 的实际资产为准）。
2. 打开 数据源，仅启用你要导入的本地工具并扫描会话；也可导入支持的公开分享链接。
3. 在 工作记录中浏览内容；若希望自动提炼知识，在 设置中主动配置并启用 AI 模型，再到 处理中心 / 知识查看结果。Embedding 与 SiYuan 同步可按需配置。

 隐私和功能边界： AIKS 不会自动访问网页账号中的私密聊天记录；本地 Provider 不修改来源文件。未配置 AI 服务时仍可浏览导入的会话，但不能自动提炼新知识。具体格式兼容性见支持矩阵。

 🌐 支持哪些 AI 数据源？

无需将不同平台的对话逐条复制到笔记软件：AIKS 统一读取支持的本地会话，并允许用户导入支持的网页公开分享链接。

 16 种本地 AI 编程 / Agent 会话

| | | | |
| --- | --- | --- | --- |
| Claude Code | OpenAI Codex CLI | Gemini CLI | OpenCode |
| Cursor | Cursor Agent | GitHub Copilot | Antigravity |
| Cline | Roo Code | Kilo Code | WorkBuddy |
| Kimi Code | Qwen Code | Continue | Aider |

本地来源默认关闭，由用户按需启用。 Provider 仅读取允许范围内的会话文件，不修改上游原始记录。不同工具版本、文件格式、安装路径的实际兼容范围有所不同，参见 详细支持矩阵。

 8 种网页 AI 对话公开分享来源

| | | | |
| --- | --- | --- | --- |
| ChatGPT | Claude | Gemini | DeepSeek |
| 豆包 Doubao | Kimi | 腾讯元宝 Yuanbao | 通义千问 Qwen |

可通过分享链接导入所支持的公开对话内容，无需统一登录各平台账户；网页结构变化可能导致特定链接解析失败。此处是公开分享链接导入，不是读取浏览器登录账户中的所有私有聊天历史。

 为什么需要 AIKS？

我们已经习惯让 AI 协助排查故障、讨论架构、编写代码和完善方案。但这些对话分散在不同的助手和工作区里：问题解决了，结论却往往留在历史记录中。过几周遇到类似问题，又要重新寻找上下文、重新解释、重新推理。

AIKS 解决的不只是“把聊天记录集中起来”，而是把 AI 协作过程变成一套可以持续复用的个人知识资产：

- 找回过程：从多个 AI 工具只读采集 Session，不需要逐条复制粘贴。
- 提炼结果：把冗长对话中的问题背景、关键步骤、解决方案整理为结构化知识，而不只保存摘要。
- 连接上下文：知识能够关联来源会话、项目和文档，必要时追溯原始讨论。
- 在下一次工作中使用：通过关键词、可选的向量语义检索和知识问答，复用过去解决过的问题。
- 始终由用户掌控：本地优先、处理过程可观察，错误知识可管理；作废时清理 AIKS 管理的知识和索引，保留以后重新导入的可能。

 一句话：从“AI 帮我完成一次任务”，走向“每次与 AI 协作都在积累下次可用的经验”。

 值得关注的核心亮点

 01 · 多种 AI 工具，一个工作记录入口

不同助手的数据格式各不相同。AIKS 通过 Provider 适配器统一为 Canonical Session，支持本地历史记录与部分公开分享对话导入。可以在工作记录中按来源浏览、预览、筛选并定位原始上下文，不需要重新打开各个工具逐条翻找。


 02 · 不止归档：自动把长对话提炼成知识

采集只是第一步。AIKS 的持久化流水线会按步骤进行解析、清洗、切分、AI 提炼以及可选的向量索引构建；知识条目可以包含标题、分类、摘要、正文和标签。大段技术排查
