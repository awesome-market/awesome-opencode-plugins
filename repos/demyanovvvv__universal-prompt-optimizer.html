Universal Prompt Optimizer v5.16

Language: English · Русский README

Quick links: Usage guide · Installation · Commands · OpenCode settings · Compatibility · Configuration guide · Changelog

Model-aware optimization of coding-agent prompts. Preserves user intent and
constraints without extra model calls.

Write a natural request. The active agent applies only useful guidance for its
resolved model and executes in the same model turn. Clear requests stay lean;
complex tasks receive a concise, task-relevant execution brief.

The goal is higher first-pass success, fewer scope errors and repair iterations,
and lower total tokens per completed task. No separate optimizer LLM call is required.

 Core capabilities

- Adaptive preflight: PASS keeps precise requests lean, LIGHT adds a missing
  boundary, and FULL builds a concise brief for complex tasks.
- Exact model routing: 34 internal profiles cover supported OpenAI, Claude,
  DeepSeek, GLM, Gemini, and other models. Unknown or ambiguous IDs follow the
  configured generic or skip policy without guessing a model variant.
- AUTO / PREVIEW / OFF: choose silent adaptation, review before execution,
  or disabled automatic optimization. PREVIEW guarantees depend on the host;
  OpenCode v1 provides advisory confirmation.
- OpenCode controls: a compact status indicator, a native command-palette
  menu with current setting values, and session/project/global save targets.
- Local-only operation: no telemetry or hidden network calls; prompt text is
  not persisted as metrics. Host permissions and user constraints remain authoritative.
- Repeatable installation: project/global installs, atomic writes, rollback,
  read-only diagnostics, and cleanup of stock legacy model commands while
  preserving custom instructions and unrelated commands.

 Supported agents

OpenCode, OMP (Oh My Pi), Pi, DeepSeek Harness, Gemini CLI, Cursor, Claude Code, OpenAI Codex,
GitHub Copilot CLI, and Windsurf. Native model visibility and PREVIEW capabilities vary by adapter;
see the compatibility matrix.

For OMP installation, commands, and approval limitations, see the OMP adapter guide. OMP has its own native extension; the Pi package is not interchangeable with OMP.

For DeepSeek Harness, --scope global --agents deepseek-harness --auto (alias dsh) installs and registers a native Desktop plugin with an icon and English/Russian display text. In the Components list it uses the short ID prompt-optimizer; the installed package and profile dependency remain universal-prompt-optimizer. Project-scope CLI launches retain the explicit .dsh/prompt-optimizer.patch.yml overlay. Uninstall removes only Harness entries recorded as installer-owned. See the DeepSeek Harness guide.

 Universal commands

| Command | Purpose |
|---|---|
| /prompt  | Detect the active model, optimize the request, and execute the task. |
| /prompt-only  | Return only the optimized reusable prompt. |
| /prompt-optimizer | Inspect or change optimizer settings. |
