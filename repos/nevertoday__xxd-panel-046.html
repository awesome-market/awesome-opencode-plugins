XXD Panel 046｜厚涂微世界

把照片重构成一座明亮、鲜活、摸得到颜料厚度的厚涂微景观。

简体中文 · English · 日本語 · 한국어 · العربية




  
    
    
  


上半是原照片，下半是这个风格画出来的样子。

 这是什么

一个给 AI Agent（Claude Code、Codex 等）用的 Skill。你给它一张照片，它按 Panel 046 的原始提示词画出一张 PNG 成品。

- 画成什么样： 主体变成一件精致立体的微缩景观，用厚涂油彩塑造，看得见颜料堆积、刮刀痕和起伏边缘。它立在明亮白色纹理纸上的一条斜向厚涂色带上，色带可以是水面、地面、小路或一道光，主体旁有倒影、波纹或光斑；背景只有几朵厚涂的云、一个太阳或一层薄雾，四周大片留白。颜色从照片里挑最明亮鲜活的几种，提亮成天空蓝、湖水青、嫩绿、暖黄、珊瑚橙这类清爽色。文字是一个简短标题加一点小字，沿色带或留白排列。
- 关键词： 厚涂 · 微缩实体 · 斜向色带 · 白底 · 温暖光感
- 能出哪些图： 上下对照（上原图、下设计）、左右对照、只要设计图，或一套手机／平板／电脑／手表壁纸。可以多选，比例和像素随你定。
- 不是什么： 不是滤镜，也不是套模板：每张都从你的照片重新画，一张照片一个独立任务。

 三步用起来

1. 安装。 Claude Code、Codex 等支持 Skills 的 Agent 都能用：

bash
npx skills add https://github.com/nevertoday/xxd-panel-046 --skill xxd-panel-046


装完重开一次 Agent 会话。也可以 git clone 本仓库，再把目录链接到 ~/.claude/skills/xxd-panel-046 或 ~/.codex/skills/xxd-panel-046。

2. 确认 Agent 能生图。 这个 Skill 不自带生图模型，用的是你 Agent 的生图能力，首选 GPT Image 2。

- Codex 开着内置生图时直接能用。
- Claude Code 等没有内置生图的 Agent，需要接一个 OpenAI 兼容的生图接口，五分钟配好，见没有内置生图怎么配。

不确定也可以直接用。不能生图时 Skill 会先停下来告诉你，不会白跑。

3. 发照片，说一句话：

 用 xxd-panel-046 把这张照片做成 3:4 上下对照海报，配中文标题。

说清楚了就直接出图；没说到的（版式、比例、文字）它会问你，通常一两个问题。成品是 PNG，放在 ~/Desktop/xxd/xxd-panel-046/ 下本次任务的新文件夹里。

 什么照片效果好

效果好

- 能做成小模型的主体：一座小屋、一艘小船、一棵树、一座桥
- 有水、路或光的场景：湖边、海岸、林间小道、日落
- 想做成明亮治愈的海报、旅行纪念或壁纸的照片

不太合适

- 阴暗、低沉或要保留昏暗气氛的照片，这套风格会把颜色提亮
- 人很多、需要认出每个人长相的照片
- 想要灰调莫兰迪、做旧暗褐、卡通玩具或光滑塑料 CG 的效果

 常用说法

不用记参数，直接说就行：

| 你想要 | 直接这样说 |
|---|---|
| 上下对照 | 做成 3:4 上下对照 |
| 左右对照 | 做成 16:9 左右对照，左边放原图 |
| 只要设计图 | 只要设计，不要原图，9:16 竖版 |
| 一套壁纸 | 做一套手机、平板、电脑、手表壁纸，风格连起来 |
| 一次多种比例 | 同一张做 1:1、3:4、16:9 各一张 |
| 用自己的文字 | 标题就写「让风经过这里」，一个字都别改 |
| 不要文字 | 不要任何文字 |
| 指定文字语言 | 文字用日语 |
| 整个文件夹 | 把这个文件夹里的照片都做成上下对照 |
| 沿用上次 | 沿用上次的设置 |

习惯命令行也行，参数和上面一一对应：

text
/xxd-panel-046 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale zh-CN
/xxd-panel-046 photo.jpg --mode design-only --size 9:16 --text none
/xxd-panel-046 ./photos --mode left-right --size 16:9 --text prompt --locale en-US


全部参数见参数参考。

 常见问题

一定要放原照片吗？ 不用。说「只要设计图」或者做壁纸，整张都是设计。

文字是谁写的？ 默认由生图模型看着你的照片现写，你只定语言。要用自己的字就直说，会一字不改；也可以完全不要字。看起来像事实的信息（地名、日期、数字）只用你给的或照片里看得见的，不会编。

不满意怎么办？ 说「再来一张」。它会从原照片重新画，而不是在上一张上修改，所以每次结果都不一样。

批量会不会串？ 不会。每张照片单独生成，不借用别的照片的颜色、文字或构图。整批只问一次设置。

我的照片会发到哪里？ 只发给你自己的 Agent 所用的生图模型。Skill 不往别处上传，也不在输出里显示接口地址和密钥。

和其他 Panel 是什么关系？ XXD Panel 是一组风格，一个编号一种，互不影响，可以只装你喜欢的。想让 AI 按照片推荐风格，或者一次比较几个风格，用总目录 xxd-panel-all。

 原始提示词

这个风格完全由小小东写的原始提示词决定。Skill 只在后面追加你选的版式、尺寸和文字设置，不总结、不翻译、不改写它。

 没有内置生图怎么配

需要一个支持 gpt-image-2（或兼容模型）的 OpenAI 兼容接口和它的 API Key。下面单独建一份配置，不影响你 Codex 本身的设置：

bash
mkdir -p ~/.xxd-imagegen
cat  ~/.xxd-imagegen/config.toml  ~/.zshrc
echo 'export XXD_IMAGE_API_KEY=你的密钥'  ~/.zshrc


重开终端和 Agent 后，在本 Skill 目录里检查一次：

bash
python3 scripts/configured_imagegen.py probe


输出 "ok":true 就是通了；它
